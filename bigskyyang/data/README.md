# 웹 제품 원본

`web_products_20261105.xlsx`는 준혁님이 새로 전달한 11-05 수정본의 원본 사본이다. 제품 2,206개이며, 하루 성분 함량이 모두 비어 있는 61개는 식이섬유 제품이다. 기존 `junhyeok/output/web_products.csv`는 11-04 자료이므로 이번 갱신에 사용하지 않는다.

저장소 루트에서 `python bigskyyang/scripts/build_supplement_catalog.py`를 실행하면 웹 제품 JSON을 다시 만든다. `--source`로 CSV 또는 엑셀을 지정할 수도 있다. 원본 파일은 수정하지 않으며, 웹 JSON에 원본 경로와 SHA-256을 기록한다. 제품 표시 문구와 같은 영양소·대상 안의 순서를 유지한다.

상한 비교 기준은 [보건복지부·한국영양학회 2025 한국인 영양소 섭취기준 요약본](https://health.seoulmc.or.kr/uploadFiles/2025_%ED%95%9C%EA%B5%AD%EC%9D%B8%EC%98%81%EC%96%91%EC%86%8C%EC%84%AD%EC%B7%A8%EA%B8%B0%EC%A4%80_%ED%99%9C%EC%9A%A9.pdf)의 xv~xx쪽을 확인했다. 답변의 칼슘 상한은 30세 이상 값이므로, 웹에서는 19~29세의 별도 상한도 적용한다. 마그네슘은 식품 외 급원, 엽산은 강화식품·보충제, 비타민 A는 레티놀 기준으로 구분한다. 비타민 A를 식품 외 섭취에만 해당한다고 안내하지 않는다. 형태를 알 수 없는 니아신·비타민 A는 제품 표시량으로 보수적으로 비교한다.
