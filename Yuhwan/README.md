## 주요 결과 (12개 군집 기준, 숫자는 모두 코드 실행 값)

**1. 판정 기준** (결과 보기 전에 확정)
- 사람마다 본인 성별·연령의 2025 KDRI와 비교 (EAR 미만 = 부족 위험, AI 미만 = 참고)
- 유형 특이: 성별·연령 보정 오즈비 ≥ 1.2, p < 0.05, '평소처럼 먹은 사람'만으로도 오즈비 > 1
- 공통 주의: 전체 가중 미달률 ≥ 50% → 비타민 C·D·E·A, 칼슘, 엽산, 식이섬유, 칼륨
- 가중치: wt_tot / 3 (3개년 통합, 이용지침서 p47)

**2. 흡수율 반영** (2025 KDRI 원문)
- EAR에 식이 흡수율이 이미 들어 있음 (철 16/18%, 아연 40%, 엽산 DFE) → 섭취량 그대로 비교
- 음주 → 티아민 흡수 저해(2권 p240), 마그네슘 배설 증가(3권 p184): 음주 군집에서 우선순위 가산
- 흡연 → 비타민 C 증량은 KDRI가 '근거 불충분'(2권 p216) → 적용 안 함
- 같이: 비타민D→칼슘, 비타민C→철 / 따로(근거 약함): 칼슘↔철·아연, 철↔아연

**3. 영양소 모듈** (15,062명 에너지 보정 섭취 상관, k=5, 실루엣 0.216, 부트스트랩 ARI 1.0)

## 한계와 논의할 것
- **생활습관 군집의 설명력이 작음**: 성별·연령 대비 군집 추가 AUC +0.008~0.038. 과일·채소 섭취빈도 3문항(LS_FRUIT, LS_VEG1/2)을 추가하면 +0.025~0.072 → **설문에 추가 제안**
- **가격 없음** → 가성비형 대신 '간편형(1일 복용 개수당 커버율)' 임시. 가격 열이 생기면 자동 전환
- 마그네슘·아연·엽산·비타민E는 제품 함량이 없어 이름으로만 판별(커버 0.3 = 고시형 최소 30% 가정)
- 비타민K·B6·B12·오메가3·유산균·루테인·밀크씨슬은 KNHANES 섭취량이 없어 **순위 없는 참고 정보**
- 기준치 7개(티아민·리보플라빈·니아신·인·칼륨·나트륨·비타민E)는 식약처 고시 원문 대조 전
- 사후에 추가한 기준(보고서에 명시 필요): 영양소 모듈 k 동률 규칙, 제품 군집 cap100 변환·'주요 성분 포괄' 기준
- 브랜드 제품명 노출이 괜찮은지 강사님 확인 필요 (기획서: "특정 제품이 아닌 원료·성분 단위로 추천")
