# 발표용 정리: 유형별 부족 영양소 예측 (전유환 파트)

재준님 PPT용으로 정리한 자료입니다. 장마다 **제목 한 문장(메시지)**을 위에, 근거를 아래에 두었습니다. 팀장님 발표 피드백 체크리스트(존댓말, 그래프 한 줄 요약, 한계는 넘는 방법까지)에 맞췄습니다.

- 분량 제안: 본편 **8장, 약 6분 30초**. 1~6장이 최종 담당(유형별 부족 영양소), 7~8장이 초기 담당(영양제 추천)과 역할을 넘긴 과정입니다. 7~8장은 "개발 과정" 순서에 맞춰 앞쪽으로 옮겨도 됩니다. 부록 2장은 질문이 나오면 꺼내는 용도입니다.
- **재준님 시간표(11/6 09:21)에 맞춘 3분 버전**: "유형별 영양 특성 분석 3분"이면 **2장(모델, 20초로 줄여서) → 3장(결과) → 4장(유형별 패턴) → 5장(화면 규칙 검증)** 순서로 쓰고, 1장은 도입 파트에, 6장은 "개인별 영양 위험 예측" 파트 연결 문장에, 7~8장은 "맞춤 개선안·음식·영양제 안내" 파트의 개발 과정이나 부록에 넣으면 됩니다.
- 숫자 출처: 최종 결과 보고서(iM양식판 8.5~8.7절). 모든 수치는 2022–23년으로 학습하고 2024년으로 평가한 값입니다.
- 그림: GitHub `Yuhwan/보고서/fig/` 폴더의 PNG를 그대로 쓰면 됩니다(보고서와 같은 청록·황토 색).
- 표현 원칙: "추천", "처방", "부족합니다(단정)"는 쓰지 않습니다. "안내", "기준 미만 비율", "10명 중 N명"으로 말합니다.

## 1장. 문제: 유형만으로는 무엇을 챙길지 모릅니다

**제목**: 유형만 알려 주면 무엇을 챙길지 모르고, 흔한 영양소만 보여 주면 모든 유형의 화면이 같아집니다

- 성인 절반 이상이 기준 미만인 영양소가 8개입니다: 비타민D 95.8%, 비타민E 90.1%, 칼륨 77.5%, 비타민A 73.8%, 비타민C 71.5%, 칼슘 71.1%, 식이섬유 63.6%, 엽산 59.3%
- 이 8개만 보여 주면 12개 유형의 화면이 거의 같아집니다
- 그래서 질문을 바꿨습니다: "같은 성별·나이보다 **이 유형에서 더** 부족한 영양소는 무엇인가?"

**그림**: `f01_부족률.png` (한 줄 요약: "주황 막대 8개는 누구에게나 흔합니다")

**대본 (30초)**: 유형을 알려 드려도 "그래서 뭘 챙겨야 하지?"가 남습니다. 그렇다고 많은 사람에게 부족한 영양소를 나열하면, 비타민D·칼슘처럼 거의 모두에게 해당하는 것들이라 어느 유형이든 화면이 같아집니다. 그래서 같은 성별·나이와 비교해 이 유형에서 더 부족한 영양소를 찾는 문제로 바꿨습니다.

## 2장. 모델: 유형·성별·나이로 영양소 15개의 기준 미만 확률을 예측합니다

**제목**: 유형·성별·연령대를 입력으로, 영양소 15개의 기준 미만 확률을 예측하는 지도 학습 모델을 만들었습니다

| 항목 | 내용 |
|---|---|
| 정답 | 영양소 15개 각각, 본인 성별·연령대의 2025 KDRI 미만이면 1 |
| 입력 | 생활습관 유형(12) + 성별 + 연령대(5). 설문 첫 화면에서 아는 값만 사용 (섭취량은 정답의 재료라 넣지 않음: 정보 누수 방지) |
| 출력 | 유형 × 성별 × 연령대 **120개 조합**마다 "10명 중 N명"과 "같은 성별·나이 대비 몇 배" |
| 후보 | 영양소마다 10개: 로지스틱 회귀(C 0.01·0.1·1·10), 유형×성별 교호항, 그래디언트 부스팅 4개 |
| 선택 | 2022–23년 안에서 5겹 교차검증, 조사 가중 **로그 손실**, **1-SE 규칙**(차이가 오차 안이면 더 단순한 모델) |
| 최종 | 로지스틱 14개 + 부스팅 1개(철) |
| 평가 | 2022–23년(9,742명) 학습 → **2024년(5,320명)** 평가. 기준 모델은 성별·연령대만 쓴 로지스틱 회귀 |

**대본 (40초)**: 확률을 그대로 "10명 중 몇 명"으로 보여 줄 거라서 순위보다 확률이 정확해야 했고, 그래서 로그 손실로 모델을 골랐습니다. 영양소마다 10개 후보를 교차검증으로 비교했고, 차이가 오차 범위 안이면 더 단순한 모델을 고르는 1-SE 규칙을 썼습니다. 마지막 평가는 학습에 쓰지 않은 2024년 자료로 했습니다.

**부록 후보**: 단백질 하이퍼파라미터 선정 표(손실 최소 C=0.1, 더 단순한 C=0.01은 1-SE 경계 0.5189를 넘어 탈락)

## 3장. 결과: 유형은 성별·나이 이상의 정보를 주지만, 효과는 작습니다

**제목**: 15개 중 13개 영양소에서 유형을 더하면 2024년 예측이 유의하게 좋아졌습니다 (AUC +0.014~+0.040)

- 비타민D·E만 차이 없음: 거의 모두가 부족해서 유형으로 더 가를 여지가 없습니다 → 공통 안내로만 사용
- 과적합 작음: 학습 − 평가 AUC 차이 최대 0.029
- 확률이 정확함: 예측과 실제 비율 차이 최대 1.7%p → "10명 중 N명"으로 그대로 써도 됨
- **우연이 아님**: 유형 라벨을 무작위로 섞으면(200회) 향상이 사라짐(ΔAUC −0.004)
- **한계를 같이 말하기**: AUC 0.56~0.70으로 중간 수준 → 개인 진단이 아니라 "같은 조건 사람들의 경향" 안내로만 씁니다
- 복잡한 모델(부스팅·앙상블)은 나아지지 않았습니다(차이 0.003 이내)

**그림**: `f06_ΔAUC.png` (한 줄 요약: "점이 0보다 오른쪽 = 유형이 도움이 된 영양소, 13개")

**대본 (40초)**: 성별·나이만 쓴 모델과 비교하면, 유형을 더했을 때 15개 중 13개 영양소에서 2024년 예측이 좋아졌습니다. 다만 향상 폭은 0.01~0.04로 작습니다. 그래서 이 결과는 개인을 판정하는 데 쓰지 않고 "같은 유형 사람들은 이런 경향이 있다"는 안내로만 씁니다. 유형을 무작위로 섞으면 이 향상이 사라져서, 우연히 나온 결과가 아니라는 것도 확인했습니다.

## 4장. 유형별 패턴과 이유: 끼니를 거르는 유형이 더 부족합니다

**제목**: 끼니를 거르는 유형은 더 부족하고, 세 끼를 챙기는 유형은 덜 부족합니다. 차이의 82%는 식사량과 식품 선택으로 설명됩니다

- **N2 배고픈 나무늘보, S1 쉬고 싶은 예민보스, O1 아침패스 워커홀릭**: 철·인·단백질·아연이 같은 성별·나이보다 1.2~1.7배 더 부족
- **A3 밸런스 갓생러, O2 삼시세끼 워커홀릭, N3 배부른 나무늘보**: 대부분 영양소에서 0.67~0.9배로 덜 부족
- 이유 분해(군집에 쓰지 않은 식품 섭취로): 식사량만 맞추면 차이의 59%, 식품군만 맞추면 67%, **둘 다 맞추면 82%**가 사라짐
  - 예: N2는 콩류 25%·유제품 18%·과일 16%·달걀 15% 덜 먹고 식사량도 8% 적음 / A3는 콩류 38%·달걀 34%·유제품·과일 32% 더 먹음
- 그래서 영양제보다 **끼니와 식사 구성 안내**가 먼저입니다 (상관관계이며 인과는 아님)

**그림**: `f05_유형x영양소_배수.png` (한 줄 요약: "주황 = 같은 성별·나이보다 더 부족, 청록 = 덜 부족. 오른쪽 공통 8개는 유형 차이가 거의 없음")

**대본 (40초)**: 이 그림은 유형마다 같은 성별·나이 평균보다 몇 배 더 부족한지 보여 줍니다. 끼니를 자주 거르는 N2, S1, O1은 철·인·단백질이 더 부족하고, 세 끼를 챙기는 A3, O2, N3는 덜 부족합니다. 왜 그런지 식품 섭취로 나눠 보니 식사량과 식품 선택이 함께 차이의 82%를 설명했습니다. 그래서 이런 유형에는 영양제보다 끼니를 먼저 안내합니다.

## 5장. 화면 규칙과 검증: 고른 영양소가 2024년에도 실제로 더 부족했습니다

**제목**: 공통 영양소는 따로 묶고, 유형에서 더 부족한 영양소만 보여 주는 규칙을 2024년 자료로 검증했습니다 (1.09배)

- 규칙 3개를 120개 조합에 적용해 비교 → **2단 표시** 채택
  - 확률 기준(≥ 0.5): 화면당 8~9개 나열, 유형 신호가 묻힘
  - 상위 3개: 평균보다 덜 부족한데 "부족"으로 보여 주는 경우 158/360
  - **2단 표시**: 공통 8개는 늘 따로, 그 밖은 ① 확률 ≥ 0.5 또는 ② 같은 성별·나이 대비 1.2배 이상 & 10명 중 3명 이상일 때만
- 기준값(1.2배, 0.3)은 **결과를 보기 전에** 팀 문서로 정하고 고정
- **2024년 검증**: 2022–23년 자료로만 고른 항목이 2024년에 같은 성별·나이 기대치보다 **1.087배(95% CI 1.056~1.121)** 더 부족
  - 문구별: "이 유형에서 특히 많아요" 1.36배 > "식사량 점검이 먼저예요" 1.24배 > "같은 성별·나이대에서 흔해요" 1.04배 → **문구의 강도와 실제 차이 순서가 같음**
- 지금 웹 화면(11/5): "같은 유형에서 섭취가 적었던 영양소" 목록에 영양소마다 "내 유형"/"성별·나이대" 표시, 공통 8개는 아래 "대체로 섭취가 부족했던 영양소" 카드

**그림**: `f08_2024검증.png` (한 줄 요약: "모든 막대가 1보다 위 = 고른 영양소가 새 연도에도 더 부족")

**대본 (40초)**: 확률을 그대로 보여 주면 공통 영양소가 화면을 다 차지해서, 공통 8개는 따로 묶고 그 밖에서 이 유형에 더 많은 것만 보여 주는 규칙을 정했습니다. 기준은 결과를 보기 전에 정했고, 2022–23년 자료로만 고른 항목을 2024년 자료에 대 보니 기대보다 1.09배 더 부족했습니다. "특히 많아요"라고 쓴 항목이 가장 크게, "흔해요"라고 쓴 항목이 가장 작게 나와 화면 문구와 실제 차이의 순서도 맞았습니다.

## 6장. 다음 단계로: 유형은 입구, 정확도는 개인 결과가 맡습니다

**제목**: 같은 정답으로 비교하면 개인 응답 모델이 더 정확해서, 유형 결과는 입구로, 개인 판단과 제품 정보는 개인 단계로 나눴습니다

- 같은 정답(24시간 회상 KDRI 미만)·같은 2024년 평가로 세 단계를 비교: 평균 AUC **성별·연령 0.604 → 유형 0.631 → 개인 응답 0.659** (개인 − 유형 차이 13개 중 11개 유의)
- 두 결과는 대부분 같은 방향: 유형 화면의 "섭취가 적었던" 영양소는 개인 결과에서 67.5%가 "높은 편", 3.8%만 "낮은 편". 엇갈릴 때는 개인 결과가 실제에 더 가까움
- 제품 정보 연결 조건도 검토: "확률 0.5 이상"을 더하면 정밀도는 60.5% → 69.1%로 오르지만 아연 85%·철 55%의 실제 미만을 놓쳐서 **현재 규칙 유지**, "관련 제품 정보 탐색"으로 표현 (11/5 재준님·대천님 결정)
- 상대 등급의 "낮은 편"도 공통 영양소는 실제 미만이 60% 안팎 → 웹 문구를 "기준 미만 가능성 낮은 편"으로 바꿈

**그림**: `f14_개인예측_비교.png` (한 줄 요약: "점이 오른쪽으로 갈수록 정확, 개인 응답(진한 점)이 가장 오른쪽")

**대본 (40초)**: 같은 정답으로 세 단계를 비교하면 성별·나이만 쓸 때 0.604, 유형을 더하면 0.631, 본인 응답을 쓰면 0.659로 올라갑니다. 그래서 유형 결과는 내 생활을 돌아보는 입구로 두고, 개인 판단과 제품 정보는 다음 단계에서 다룹니다. 두 결과는 대부분 같은 방향을 가리켜서 사용자가 헷갈릴 일도 적습니다.

**비유 장면 아이디어 (선택)**: 유형 결과 = "서울 지역 날씨 예보", 개인 결과 = "내 위치의 날씨 예보". 지역 예보도 쓸모 있지만, 우산을 챙길지는 내 위치 예보가 더 정확합니다.

## 7장. 초기 담당: 유형 기반 영양제 추천 (11/1~11/3, 비지도 학습)

**제목**: 처음에는 "유형 → 필요 영양소 → 제품 유형 → 제품" 순서로 영양제를 고르는 구조를 비지도 학습으로 만들었습니다

- **구조**: 고객 유형 → 유형별 필요 영양소(성별·연령 보정) → ① 영양소 모듈 매칭 → 식품 안내 / ② 제품 유형 매칭 → 그 유형 안에서 장르별 상위 3개
- **① 영양소 모듈 (계층적 군집)**: 15,062명의 에너지 보정 섭취 상관으로 "같이 부족해지는 영양소" 5묶음 (k=5, 부트스트랩 ARI 1.0). 묶음 이름은 식품군 상관으로 데이터 확인
  - 비타민A·E·리보플라빈·칼슘 ↔ 유제품(0.37) / 단백질·인·철·아연 ↔ 콩류·생선·달걀 / 비타민C·엽산·칼륨·마그네슘·식이섬유 ↔ 콩류·과일·채소 / 티아민 ↔ 육류 / 비타민D ↔ 생선(0.48)
- **② 제품 유형 (k-medoids)**: 식약처 제품 4,250개를 성분 함량으로 군집해 12개 제품 유형 (cap300 변환, k=12, 재추출 ARI 0.933, 실루엣 0.798)
  - 고른 방법: 2방법 × 변환 3종 × k 17개 = 방법당 51개 설정을 같은 기준(크기 → 주요 성분 포괄 → 안정성 → 실루엣)으로 비교. **k-medoids 17/51 통과 vs 계층적 1/51**, 계층적은 마그네슘·철 유형이 사라짐
- **품질 장치**: 대상 필터(키즈·청소년·임산부 49개 제외), 식사 대용 22개 제외, 제품 주목적 판별(간·면역·모발 제품이 B1 제품처럼 보이던 문제), 종합형 분리, 상한섭취량 초과 제외, 인기·브랜드 점수는 쓰지 않음
- **변별력 지표**로 추천이 유형마다 다른지 관리: 편의형 유형 간 겹침(Jaccard) 0.44 → 0.14

## 8장. 방향 전환: 유형 기반 추천의 한계를 확인하고 개인 단계로 넘겼습니다

**제목**: 유형의 절반은 추천이 같아지고 처방처럼 보일 위험이 있어, 영양제는 개인 단계로 옮기고 제 로직은 개인용 함수로 바꿔 넘겼습니다

- **확인한 한계**
  - 공통 영양소만 해당하는 유형이 **48.8%**(당시 11개 유형 중 5개) → 이 유형들은 추천 제품이 모두 같음
  - 유형 결과는 같은 조건 사람들의 **경향**인데, 여기서 제품을 고르면 개인 처방처럼 읽힘 (의료법·표현 원칙)
  - 엽산·마그네슘 등은 제품 자료에 함량 칸이 없어 일부 유형은 추천 칸이 비었음
- **11/3 팀 회의 결정**: 유형 화면은 "부족할 수 있는 영양소"까지, 영양제는 개인 결과(재준님 예측 → 준혁님 분류)에서만
- **넘긴 것**: 추천 로직을 입력만 개인(재준님 High/Mid/Low)으로 바꾼 함수 `recommend_api.py`로 전달 (유형 기반 결과와 33/33 일치 확인). 목적 일치·종합형 분리·상한 초과 제외·인기 점수 미사용 원칙을 그대로 넘김. 이후 제품 정보는 준혁님 9단계 분류(2,227개)로 일원화
- **그 뒤 제 역할**: 유형별 부족 영양소(1~6장)와, 개인 결과 → 제품 정보 연결 조건 검증(6장의 "확률 0.5 조건" 비교)

**대본 (40초)**: 만들어 보니 유형의 절반 가까이는 공통 영양소만 해당해서 추천 제품이 똑같았고, 무엇보다 같은 유형 사람들의 경향으로 제품을 고르면 개인 처방처럼 보인다는 문제가 있었습니다. 그래서 팀 회의에서 유형 화면은 부족할 수 있는 영양소까지만 보여 주고, 영양제는 개인 결과에서 다루기로 했습니다. 제 추천 로직은 개인 예측을 입력으로 받는 함수로 바꿔 준혁님께 넘겼고, 저는 유형별 부족 영양소 분석으로 역할을 옮겼습니다.
