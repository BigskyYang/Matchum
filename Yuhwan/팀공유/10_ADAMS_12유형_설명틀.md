# 12유형을 "쓸모 있는 구분"으로 설명하는 틀 (ADAMS) — 보고서·발표 구성안

> 작성: 전유환, 2026-11-04 · 범위: 생활습관 12유형 + 유형별 부족 영양소
> 목적: 실루엣처럼 "덩어리가 뚜렷한가"를 묻는 대신, 실무 세분화 기준(ADAMS)으로 "서비스에 쓸모 있는 구분인가"를 보여 준다.

## 0. 왜 이 틀인가
- 생활습관은 이어진 분포라 뚜렷한 덩어리가 없다 (대분류 실루엣 0.163 < 무작위 자료 0.18~0.21, 12유형 수준도 지연님 확인 결과 같음 → `팀공유/09`)
- 실무 고객 세분화는 통계적 분리도보다 **ADAMS** (Accessible·Differentiable·Actionable·Measurable·Substantial)로 세그먼트를 평가한다. 핵심 원칙: *같은 방식으로 반응하는 두 그룹은 합쳐야 하고, 경계가 흐려도 다르게 대응할 수 있으면 쓸모 있는 구분이다* (OpenStax, Principles of Marketing 5.4)
- **적용 방식 (우리 해석)**: ADAMS는 원래 마케팅 기준이라 '구매 반응' 자리에 '부족 영양소 양상'과 '받는 습관 미션'을 넣어 영양 서비스에 맞게 적용했다. 이 번역은 팀의 해석임을 밝힌다
- 식이 패턴 연구도 군집을 **군집에 쓰지 않은 변수(식품·영양소 섭취)**로 검증한다 (Román-Viñas 2009, Devlin 2012) → 18번 분석이 이 방식

## 2. 차별성의 정직한 해석: 영양 차이는 "3개 무리", 생활습관 안내는 "12유형"
부족 영양소 양상(로그 관측/기대)으로 12유형을 다시 묶으면 크게 3개 무리로 나뉜다 (Ward, 18번 결과):

| 영양 무리 | 유형 | 부족 정도 (같은 성별·나이 = 1) | 식품 |
|---|---|---|---|
| 덜 부족한 무리 | N3, A1, A3, O2, O3 (끼니 규칙적) | 인 0.46~0.89, 철 0.61~0.91, 단백질 0.65~0.87 | 유제품·달걀·콩류·과일을 더 먹음 (A3 콩류 38%↑, 달걀 34%↑) |
| 조금 더 부족한 무리 | N1, A2, S1, S2, S3, O1 | 1.0~1.4 (S1 인 1.38, O1 인 1.21) | 과일·콩류·달걀을 덜 먹음 (O1 콩류 33%↓, S1 과일 17%↓) |
| 가장 부족한 유형 | N2 끼니 거르는 형 | 인 1.65, 단백질 1.44, 철 1.42, 아연 1.37 | 콩류 25%↓, 유제품 18%↓, 과일 16%↓, 달걀 15%↓, 에너지 8%↓ |

- ADAMS 원칙("같은 반응이면 합친다")을 영양소에만 적용하면 부족 양상이 거의 같은 쌍이 있다: A2–S2, N1–S2, S1–O1, A2–S3 (차이 약 4%)
- 하지만 이 쌍들은 **생활습관이 크게 다르다**: A2–S2는 스트레스·근력, S1–O1은 스트레스·유산소, N1–S2는 유산소·스트레스에서 표준편차 1.5~2.2만큼 차이 → **미션(Actionable)이 다르다**
- 그래서 구조를 이렇게 설명한다: **12유형은 생활습관 안내 단위, 부족 영양소 차이는 끼니 규칙성을 따라 3개 무리로 갈린다.** 유형 결과 화면의 영양소 안내가 몇몇 유형끼리 비슷한 것은 이 구조 때문이며, 숨길 일이 아니라 결론이다

## 2-1. 보완 계산 (19번, `영양분석/19_ADAMS_보완.py`)
**① 차별성이 일부 영양소에 몰리는 이유 = 화면 구조와 같다**
영양소마다 12유형 관측/기대의 퍼짐(로그 표준편차)을 보면, 유형 영역 후보 영양소는 평균 **0.237**, 공통 영역 영양소는 **0.068**로 3.5배 차이가 난다.

| 영양소 | 유형 간 범위 (최소~최대) | 전체 부족률 | 화면 |
|---|---|---|---|
| 인 | 0.46 ~ 1.65 | 11% | 유형 영역 |
| 단백질 | 0.65 ~ 1.44 | 22% | 유형 영역 |
| 철 | 0.61 ~ 1.42 | 26% | 유형 영역 |
| 아연 | 0.64 ~ 1.37 | 29% | 유형 영역 |
| 칼슘 | 0.86 ~ 1.10 | 71% | 공통 영역 |
| 비타민 C | 0.86 ~ 1.07 | 71% | 공통 영역 |
| 비타민 D | 0.98 ~ 1.01 | 96% | 공통 영역 |

→ 흔히 부족한 영양소(칼슘·비타민 C·D 등)는 누구에게나 비슷하게 부족해서 공통 영역에, 유형마다 차이가 큰 영양소(인·단백질·철·아연)는 유형 영역에 둔 지금 화면 구조가 데이터와 맞는다. 차별성이 일부 영양소에 몰리는 것은 약점이 아니라 화면을 두 영역으로 나눈 이유다.

**② 영양이 비슷한 유형 쌍도 미션은 다르다** (미션 = 웹 `tips.js` 유형 결과 미션 조건, 유형별 해당 비율)

| 쌍 | 영양 양상 차이 | 해당 비율이 30%p 이상 다른 미션 |
|---|---|---|
| A2–S2 | 0.039 | 하루 10분 쉬어가기 5% vs 82%, 주 2회 근력운동 30% vs 100% |
| N1–S2 | 0.040 | 하루 30분 걷기 94% vs 0%, 쉬어가기 12% vs 82%, 집밥·도시락 0% vs 48% 외 1개 |
| S1–O1 | 0.042 | 쉬어가기 91% vs 1%, 하루 30분 걷기 100% vs 52% |
| A2–S3 | 0.042 | 쉬어가기 5% vs 98%, 1시간마다 일어나기 26% vs 59%, 집밥·도시락 27% vs 58% 외 1개 |
| S2–S3 | 0.050 | 주 2회 근력운동 100% vs 0% |

→ ADAMS 원칙("같은 반응이면 합친다")을 영양에만 적용하면 합칠 후보지만, **받는 미션이 다르므로(Actionable) 합치지 않는 것이 맞다.**

**③ 경계에 있는 사람도 안내 품질이 비슷하다** (08_군집경계_진단, 2024 AUC 15개 영양소 평균)
유형 핵심 0.637 (2,343명) / 중간 0.639 (2,010명) / 경계 0.623 (967명), 핵심 − 경계 평균 **0.014**. 재표본에서 유형이 바뀌는 사람이 주로 경계에 있지만, 그 사람들에게 주는 영양 안내의 정확도는 크게 떨어지지 않는다.

## 3. 부족 영양소 추천의 설득력: 생활습관 → 식품 → 영양소
- 18번: 부족 차이(10% 이상 칸)의 **평균 67%는 무엇을 먹느냐(식품 선택), 16%는 얼마나 먹느냐(식사량)**로 설명됨
  - N2: 식품 선택 63% · 식사량 25% → "끼니를 거르면서 콩·유제품·달걀을 덜 먹어서"
  - S1: 식품 선택 64% · 식사량 15%, 에너지 0.99배 → 덜 먹는 게 아니라 **무엇을 먹느냐** (현재 판정표의 '식사량 관련'과 다름 → 팀장님 확인 요청함)
  - O1: 식품 선택 37% · 식사량 49% → 외식·결식으로 양 자체도 줄어듦
- 14번 습관 연결표: 같은 성별·나이 안에서 아침 거르기 → 엽산·마그네슘 +1.6명, 아연 +1.5명 (10명 중); 점심·저녁 거르기 → 아연 +1.6명, 철 +1.4명
- 선행 연구와 같은 방향: KNHANES 분석에서 아침을 먹는 노인이 칼슘·철·식이섬유 섭취가 높았고(J Nutr Health Aging 2024), 20~64세 성인에서도 아침 결식군이 대부분 영양소 섭취가 가장 낮았다(J Nutr Health 51(6))
- 검증: 2022–23 학습 → 2024 확인에서 유형 영역 항목이 실제로 더 부족(관측/기대 1.087 [1.056, 1.121]), 확률 보정 오차 ≤ 1.7%p

## 3-1. 유형 트랙과 개인화 트랙의 경계
이 구성안의 분석(식품군 연결 고리, 영양 3무리)은 모두 **유형 평균**을 설명한다. 사용자에게 식사를 묻거나 개인 확률을 계산하지 않으므로 개인화가 아니다.

| | 유형 트랙 (이 구성안) | 개인화 트랙 (재준·준혁님) |
|---|---|---|
| 입력 | 1단계 생활습관 설문 → 12유형 + 성별 + 연령대 | 개인 응답 18개 + 평소 식사 5문항 |
| 결과 단위 | 120가지 조합으로 고정 (같은 조합이면 같은 결과) | 사람마다 다름 |
| 식품 정보 | 그 유형 사람들의 평균 식품 섭취 (국민건강영양조사) | 본인이 답한 식사 문항 |
| 영양제 정보 | 없음 | 있음 |
| 알려 주는 몫 | 성별·나이 대비 AUC +0.027 (0.604 → 0.631) | 유형 대비 +0.028 더 (→ 0.659) |

표현 규칙 (화면·보고서·발표 공통)
- 주어는 항상 **"이 유형은 평균적으로"**: "이 유형 사람들은 평균적으로 콩류·유제품을 덜 먹는 편이라 철이 부족한 경우가 많아요" (O) / "당신은 콩류를 덜 먹어서 철이 부족해요" (X, 1단계 설문은 식사를 묻지 않음)
- 식품 이야기는 유형 평균으로만, 영양제 이야기는 개인화 트랙에서만
- '이번 주 해볼 것'은 본인 응답에 해당하는 습관만 보여 주지만(팀장님 설계), 생활습관 안내라 영양소 판단·영양제와 관계없음. 근거 문장도 "아침을 챙기는 사람은 ○○ 부족이 적은 편이에요"처럼 집단 경향으로
- 발표 질문 "개인화랑 뭐가 달라요?" → "유형 결과는 같은 유형·성별·나이 사람들의 평균이고, 그 안에서 사람마다 다른 부분은 개인 결과가 맡아요. 숫자로도 두 단계가 알려 주는 몫이 따로 있어요"

## 4. 발표 흐름 제안 (5장)
1. **문제**: 생활습관은 이어진 분포 → "덩어리 찾기"가 아니라 "쓸모 있는 구분 만들기" (실루엣·귀무 검정 결과를 솔직하게)
2. **ADAMS 표** (1절): 다섯 기준을 숫자로 통과
3. **영양 3무리 × 생활습관 12유형** (2절 표): 끼니 규칙성이 영양 차이를 가르고, 같은 영양 무리 안에서도 미션이 다름
4. **왜 부족한가**: N2·A3 대비 예시로 생활습관 → 식품 → 영양소 고리 (3절), 식품 선택 67% · 식사량 16%
5. **화면으로**: 유형 결과(공통 영역 + 유형 영역 + 바꿀 습관) → 개인 결과(성별·나이 0.604 → 유형 0.631 → 개인 0.659)

## 5. 한계 (보고서에 그대로)
- 18번의 식품군과 영양소는 같은 하루 기록에서 나와 "차이가 어떤 식품에서 오는지" 나눈 분석이며 독립 검증은 아님 (과일·채소 빈도는 설문이라 독립)
- 식품군이 5개(육류·생선·유제품·달걀·콩류)뿐이라 곡류·채소 g은 없음
- 상관관계: "~를 먹으면 좋아져요" 같은 인과 표현 금지
- 하루 24시간 회상 기준이라 평소 섭취와 다를 수 있음
- 세부 유형 S3(3.6%)·O3(4.7%)는 작아서 유형별 수치가 더 흔들릴 수 있음

## 6. 이 틀의 강점 · 약점 · 보완 · 한계
**강점**
1. 약점을 숨기지 않는다: 실루엣·귀무 검정 결과를 그대로 보여 주고 "덩어리는 없지만 쓸모 있는 구분"으로 답한다
2. 실무 기준(마케팅 세분화 ADAMS)과 연구 관행(군집에 쓰지 않은 변수로 검증)을 따른다
3. 다섯 기준 모두 숫자 근거가 있다 (최소 크기 3.6%, 재배정 100%, 72/156칸, 미션 차이)
4. "12유형 = 생활습관 안내 단위, 영양 차이 = 3무리"로 구조가 논리적으로 설명된다
5. 생활습관 → 식품 → 영양소 고리로 추천에 이유가 생긴다 (식품 선택 67%, 식사량 16%), 선행 연구와 방향이 같다
6. 유형 평균만 쓰고 표현 규칙을 정해 개인화 트랙과 경계가 분명하다

| 영양이 거의 같은 유형 쌍 | 쌍별 미션 해당 비율 비교 (2-1 ②) | 5쌍 모두 30%p 이상 다른 미션이 1~4개 → 합치지 않는 근거 |
| 경계 고객의 유형이 바뀜 (재표본 ARI 0.697) | 핵심·중간·경계 AUC 정리 (2-1 ③) | 차이 0.014로 안내 품질은 비슷 |
