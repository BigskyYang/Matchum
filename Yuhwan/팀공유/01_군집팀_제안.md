# [제품분석] 군집팀 제안 4가지 (재준님, 지연님)

> 현재 12개 Sub 군집 기준 분석. 코드·결과는 [Yuhwan/README.md](../README.md)

## 1. 현재 군집이 영양 부족을 얼마나 설명하는지
- 성별·연령만으로 영양 부족을 예측할 때보다, 군집을 더하면 AUC가 **+0.008~0.038** 올라감 (9개 영양소, 5-fold 교차검증)
- 과일·채소 섭취빈도 3문항을 더하면 **+0.025~0.072** → 군집 효과의 2~5배
- 전체의 63%가 속한 큰 군집 4개(1-0, 1-1, 3-1, 3-2)는 특별히 부족한 영양소가 안 나와서 추천이 모두 같아지는 문제가 있음

| 부족 위험 예측 AUC | 성별·연령만 | + 군집 | + 과일·채소 빈도 |
|---|---|---|---|
| 비타민 C | 0.547 | 0.585 | 0.658 |
| 식이섬유 | 0.597 | 0.612 | 0.667 |
| 마그네슘 | 0.598 | 0.613 | 0.651 |
| 칼륨 | 0.638 | 0.646 | 0.683 |
| 비타민 A | 0.567 | 0.577 | 0.614 |

## 2. 새 군집에 성별·연령을 넣을 때
- 성별(0/1)이 군집을 반으로 갈라버리지 않는지 확인 부탁: 변수별 **"군집 간 분산 ÷ 전체 분산"**을 보면 됨
- 성별 값이 1.0에 가까우면 생활습관 유형이 아니라 "남자/여자 군집"이 될 수 있음

## 3. 설문에 과일·채소 문항 추가 (설문 담당과 같이)
- KNHANES 문항 그대로: `LS_FRUIT`(과일), `LS_VEG1`(채소, 김치 포함), `LS_VEG2`(채소, 김치 제외)
  - 보기 9단계: 하루 3회 이상 / 하루 2회 / 하루 1회 / 주 5-6회 / 주 2-4회 / 주 1회 / 월 2-3회 / 월 1회 / 거의 안 먹음
- 1년 평균 빈도를 묻는 설문이라 24시간 회상 기록과 따로 수집됨 → 누수 없음
- 군집 입력 변수로 넣기보다는 **"군집 × 과일·채소 적게/보통" 칸으로 나누는 보정 축**으로 쓰는 걸 제안
  (군집에 넣으면 "채소 안 먹는 군집이 비타민C 부족" 같은 뻔한 결과가 될 수 있음)

## 4. 웹 연결용으로 받고 싶은 것
- ID + 군집 라벨 파일 (csv)
- 웹에서 설문 응답자를 군집에 배정하려면 **단계별 scaler와 군집 중심**이 필요 (pkl이나 json으로 저장 부탁)
- 참고: 군집별 "부족 영양소 개수"(EAR 기준 11개 중)를 계산해보니 **4.35~6.25개**로 차이가 있음 → 군집 해석에 활용 가능
