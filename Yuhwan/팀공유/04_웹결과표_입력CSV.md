## 2. 확인할 점 ① 지금 스크립트는 KMeans 파일 형식 기준
- `Main_Cluster` 열을 읽는데, 지연님 11개 유형 파일(`Jiyeon/KMedoids_Lifestyle_MicroClustered.xlsx`)은 **`Macro_Cluster`**
- 유형 ID는 `model.json`의 `typeIds`에서 찾는데, 지금 `model.json`은 KMeans 3단계 결과 → 11개 유형 라벨이 없어서 멈춤
- 테스트는 임시로 `Macro_Cluster → Main_Cluster` 이름 변경 + `typeIds = 라벨 그대로`로 돌림 → 15,062명 전원 결합, 유형 18개(대분류 7 + 세부 11) 생성 확인
- → `export_model.py`를 k-medoids 11개 유형(PCA + k-medoids, 세부 분할)에 맞게 바꾸는 작업이 필요해 보여요

## 3. 확인할 점 ② Low/Mid/High 구간이 '유형 평균 비율'에 안 맞음
`Jaejun/config/risk_thresholds.json`은 **사람별 예측확률 분포**로 정한 구간인데, 결과표는 **유형별 평균 비율**에 그 구간을 적용해서 결과가 쏠려요.

| 영양소 | low_mid | mid_high | 유형별 실제 비율 | High인 유형 (18개 중) |
|---|---|---|---|---|
| 인 | 0.008 | 0.052 | 0.07 ~ 0.22 | **18개 전부** (가장 건강한 유산소형도 High) |
| 단백질 | 0.024 | 0.231 | 0.18 ~ 0.37 | 9개 |
| 철 | 0.061 | 0.302 | 0.16 ~ 0.35 | 7개 |
| 칼슘 | 0.698 | 0.880 | 0.67 ~ 0.78 | **0개** |
| 비타민A·엽산·칼륨·마그네슘·B1·식이섬유 | | | | **0개** |

→ 화면에 "모든 유형이 인 High, 칼슘은 어느 유형도 High 아님"으로 나옴

**제안**: 유형 결과표는 '절대 구간' 대신 **유형끼리 비교한 상대 위험**으로 표시
- 제품분석에서 이미 계산한 등급을 그대로 쓸 수 있어요: `영양분석/02_군집별_영양니즈.py`
  - **유형 특이** = 성별·연령 보정 오즈비 ≥ 1.2 (p < 0.05, 평소처럼 먹은 사람만으로도 유지)
  - **공통 주의** = 전체 미달률 ≥ 50% (모든 유형에 공통 안내)
- 또는 간단히 "유형 비율 ÷ 전체 비율"(예: 1.2배 이상이면 High)
- 사람별 Low/Mid/High(모델 확률)는 지금 구간 그대로 쓰는 게 맞음 — 문제는 유형 평균에 적용할 때만
