# [제품분석] 가성비 추천용 제품 가격 조사 요청 (작성 가이드)

**파일: [`가격조사_대상.xlsx`](가격조사_대상.xlsx)** — 제품 162개 (`가격조사` 시트에 입력, `작성방법` 시트에 이 문서 요약)

> 왜 필요한가요? 식약처 건강기능식품 데이터에는 **가격이 없어서** 지금은 '가성비형' 대신 임시로 '간편형(알약 수 기준)'을 보여주고 있어요.
> 가격이 채워지면 코드가 **하루에 드는 돈**을 계산해서 '가성비형' 추천으로 자동으로 바뀌어요.
> 전체 5천 개가 아니라, 11개 생활습관 유형별로 **실제 추천 후보가 될 제품만** 뽑았어요.

## 1. 엑셀 칸 설명

엑셀을 열면 헤더 색으로 구분돼 있어요. **회색 = 미리 채워둔 칸(건드리지 않기)**, **노란색 = 채울 칸**

### 회색 (미리 채워둔 칸)
| 칸 | 뜻 | 예시 |
|---|---|---|
| `1회분량` | **한 번** 먹을 때의 양 (식약처 표시 기준) | `2정` → 한 번에 2정 |
| `1회분량중량` | 1회분량의 무게·부피. **분말·액상**의 총개수를 계산할 때 씀 | `31000mg` = 31g, `20ml` |
| `1일섭취횟수` | **하루에 몇 번** 먹는지 | `2` → 하루 2번 |
| `1일개수` | **하루에 먹는 총 개수** = 1회분량 숫자 × 1일섭취횟수 (단위는 1회분량과 같음) | `2정` × 2번 = **4** (하루 4정) |
| `총개수_제품명추정` | 제품명에 "(112정)"처럼 적힌 숫자를 **자동으로 뽑아둔 참고값**. 143개 중 5개만 있고, 틀릴 수 있어서 **판매 페이지로 꼭 확인** | `센트룸실버맨(112정)` → 112 |
| `검색어` | 네이버쇼핑에 그대로 붙여넣을 검색어 (제품명 + 제조사) | |
| `1일가격(자동)` | 판매가격과 총개수를 넣으면 **자동 계산** (아래 3번) | |

⚠️ `총개수_제품명추정`이 틀린 실제 예: `숫사슴 녹혈 8000 플러스 (800mg x 100정)` → 제품명은 **100정**인데 1회분량은 **1캡슐**이에요. 이런 경우는 판매 페이지에서 실제 개수를 확인하고, 단위가 다르면 비고에 적어주세요.

### 노란색 (채울 칸)
| 칸 | 넣을 값 | 예시 |
|---|---|---|
| `판매가격(원)` ★ | 한 통(단품)의 판매가. **숫자만** (원·쉼표 없이) | `23900` |
| `총개수` ★ | 한 통에 든 개수. **1회분량과 같은 단위로** (정이면 정, 포면 포, 스쿱이면 스쿱) | 120정짜리 → `120` |
| `판매처` | 가격을 본 쇼핑몰 | `쿠팡`, `네이버 스마트스토어(OO약국)` |
| `URL` | 상품 페이지 주소 (가격비교 목록 말고 실제 상품 페이지) | |
| `조사일` | 조사한 날짜 | `2026-11-03` |
| `비고` | 특이사항 | `없음` / `해외직구` / `세트만 있음` / `단위 다름` |

★ 두 칸이 꼭 필요해요. 나머지는 나중에 확인용이에요.

## 2. 가격 찾는 순서 (한 제품당 1~2분)
1. `검색어` 칸을 복사해서 **네이버쇼핑**에 검색
2. **같은 제품인지 확인**: 제품명·제조사·1회분량(예: 1캡슐)이 맞는지
3. 가격비교에서 **단품 최저가** 클릭 → 상품 페이지에서 가격과 **한 통 개수** 확인
4. `판매가격(원)`, `총개수`, `판매처`, `URL`, `조사일` 입력
5. 옆의 `1일가격(자동)`이 **상식적인지** 확인 (보통 하루 100원 ~ 3,000원 정도. 수만 원이면 총개수 단위를 다시 확인)

## 3. 1일가격은 이렇게 계산돼요
> **1일가격 = 판매가격 ÷ (총개수 ÷ 1일개수)**
>
> 예) 판매가 30,000원, 한 통 120정, 하루 4정(1회 2정 × 2번)
> → 120 ÷ 4 = **30일분** → 30,000 ÷ 30 = **하루 1,000원**

그래서 `총개수`를 1회분량과 **다른 단위**로 넣으면 계산이 틀어져요. (예: 1회분량이 "1포"인데 총개수를 그램으로 넣으면 안 됨)

## 4. 헷갈리는 경우 기준 (모두 같은 기준으로!)
| 상황 | 이렇게 |
|---|---|
| 가격이 여러 개 | 가격비교의 **단품 최저가**. 배송비·쿠폰·카드할인·멤버십 할인은 **빼고** 표시가 그대로 |
| 2개·3개 **묶음**만 있음 | 묶음가 ÷ 개수, 비고에 `세트만 있음` (예: 2개 39,800원 → `19900`) |
| 용량이 여러 개 (60정/120정) | 제품명에 용량이 있으면 **그 용량**, 없으면 판매 페이지의 **가장 작은 기본 용량** |
| **분말**(스쿱·포) | 총개수 = 라벨의 **"총 ○회분"**. 없으면 **총 내용량 ÷ 1회분량중량** (예: 900g ÷ 31g = `29`) |
| **액상**(병·ml) | 한 박스에 든 병 수 (예: 10병입 → `10`) |
| **해외직구**만 있음 | 원화 가격 그대로(배송비 제외), 비고에 `해외직구` |
| 단종·품절·검색 안 됨 | 판매가격·총개수 **비우고** 비고에 `없음` |
| 맛만 다른 제품 (프로틴 여러 맛) | 행마다 따로 채움 (가격이 같으면 같은 값) |
| 같은 이름인데 제조사가 다름 | 제조사가 같은 제품으로. 없으면 비고에 `제조사 다름` |
