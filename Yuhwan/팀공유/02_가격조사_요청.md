# [제품분석] 가성비 추천용 제품 가격 조사 요청

**파일: [`가격조사_대상.xlsx`](가격조사_대상.xlsx)** (이 폴더, 제품 124개)

군집별로 실제 추천 후보가 될 제품만 뽑은 것이라 전체 5천 개를 다 할 필요는 없음.
(뽑은 기준: 군집마다 매칭된 제품 유형 3개 × 유형별 커버율 상위 10개 + 현재 추천 제품)

## 채울 칸
`판매가격(원)` / `총개수` / `판매처` / `URL` / `조사일` (`비고`는 선택)

식품명·제조사·1회분량·1일개수·검색어는 미리 채워둠. `총개수_제품명추정`은 제품명에서 뽑은 참고값이라 확인 필요.

## 기준 (다 같은 기준으로 맞춰주세요)
- 네이버쇼핑 가격비교에서 **단품 최저가** (묶음·정기구독·쿠폰 할인 제외, 배송비 제외)
- 총개수는 `1회분량` 칸과 **같은 단위**로 (예: 1회분량이 "2정"이면 한 통에 든 **정** 수)
- 용량이 여러 개면 제품명에 적힌 용량, 없으면 가장 기본 용량
- 같은 날 조사 (가격 변동 때문에)
- 못 찾은 제품은 `비고`에 "없음"이라고만

## 기한과 반영
- 가능하면 **11/4(1차 완성일) 전**까지
- 채운 파일을 `Yuhwan/제품분석/output/가격조사_대상.xlsx`에 두고 `04_제품추천.py`를 다시 실행하면, 코드가
  **1일 가격 = 판매가격 ÷ (총개수 ÷ 1일개수)**를 계산해서 '간편형'을 **'가성비형'**으로 자동 전환함 (가격 30개 이상일 때)
