# [참고용] 개인화 트랙 비교: 성별·나이 → 유형 → 개인 모델 (전유환, 11/4)

> ⚠️ **참고용 분석입니다.** 재준님 v1.4 개인 모델을 성별·나이 모델, 유형 모델과 같은 조건에서 비교한 **평가**예요.
> - 웹이나 모델이 이 결과를 읽지 않고, 재준님 모델·웹 등급 기준도 바꾸지 않아요.
> - 발표·보고서에서 "왜 유형 다음에 개인 단계를 두었나"의 근거로만 써 주세요.
> - 3번(유형 대비 등급)은 **검토했지만 채택하지 않은 안**이에요. 지금 세 등분 방식이 더 나아요.

## 조건
- 같은 사람(15,062명), 같은 정답(2025 KDRI 기준 미만), 같은 분할(2022–23 학습 → 2024 검증 5,320명), 같은 조사 가중치
- 기준 모델: 성별 + 연령대 (로지스틱) / 유형 모델: 12유형 + 성별 + 연령대 (`영양분석/08`에서 고른 설정)
- 개인 모델: 재준님 v1.4 생활습관 모델 그대로 (웹 `bigskyyang/web/src/data/nutritionModels.json` 트리를 재현, 입력 18개). 재준님 보고 AUC와 평균 0.001 차이 → 재현·정답 정의 확인
- 나트륨 과잉은 우리 정답이 없어 제외 (13개 영양소)
