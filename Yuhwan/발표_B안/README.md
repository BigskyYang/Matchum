## 확인 부탁
- 개인화 장(23)·부록 A8 숫자는 **현재 시안 기준(진행 중 표시)** → 재준님·준혁님 확정 후 갱신 필요
- 글꼴은 발표 PC 호환 위해 맑은 고딕
- 군집 수치는 지연님·팀장님 결과 인용 — 담당 부분 확인 부탁

## 다시 만들기
`npm install` → `node build_deck.js` (숫자는 `data.json`, 웹 캡처는 `node capture_web.js`, PDF는 `render.ps1`). 이미지는 `img/` (웹 마스코트·matchum.vercel.app 예시 응답 캡처).
