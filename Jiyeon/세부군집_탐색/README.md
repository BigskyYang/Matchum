# 세부 군집 변수 선정 근거 (재현 탐색)

- 대분류 배정: `KMedoids_Lifestyle_12Types.xlsx`의 `Macro_Cluster`
- 7개 변수의 2개·3개 조합 전부(대분류당 56개)를 k=3 K-Medoids로 군집화
- 시드 5개(0~4), 시드당 시작 3회. 실루엣·군집 크기·기여도는 시드 0의 해 기준
- **기여도** = 각 변수의 η² (세부 군집 간 분산 / 대분류 내 전체 분산). 0에 가까우면 그 변수는 나누는 데 쓰이지 않은 것
- 0/1 변수: 유산소(`aerobic`), 스트레스(`stress`)
- 실행: `python sub_search.py <Jiyeon 폴더> sub_all.csv all 3` → `sub_all.csv`, `sub_all_sd.csv`

최종 선택한 4개 조합의 실루엣, 군집 크기, 기여도는 `cluster_report.md` 4장의 값과 일치한다.

세부 군집 수 확인: `python sub_k_compare.py <Jiyeon 폴더> sub_k.csv` → 선택된 조합마다 k=2~5의 실루엣·ARI·최소 군집 비교. 결과는 `cluster_report.md` 4장 "세부 군집 수(k) 확인"에 정리했다.

## 선정 규칙

| 단계 | 기준 | 거르는 대상 |
|---|---|---|
| ① 안정성 | 시드 간 평균 ARI ≥ 0.95 | 시드마다 결과가 달라지는 조합 |
| ② 크기 | 가장 작은 군집 ≥ 12% | 100~400명짜리 소수 군집 |
| ③ 실제 기여 | 모든 변수의 기여도가 충분함 | 한 변수만으로 갈리는 조합 (3변수 조합은 통과한 것 전부 한 변수의 기여도가 0.08 이하) |
| ④ 연속 변수 | 0/1 변수(유산소·스트레스) 제외 | 실루엣이 부풀려지는 조합 |
| ⑤ 실루엣 | 남은 조합 중 최고 | — |
