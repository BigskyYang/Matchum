# 개인별 영양제 제안 파트 (박준혁)

식약처 건강기능식품 신고 자료를 기준에 따라 걸러서, 웹에서 "이런 제품도 있어요"로 보여 줄 **영양제 후보**를 만드는 작업이에요.
영양제를 **처방하는 게 아니라 정보로 제안**해요. 의약품은 다루지 않고, 가격·브랜드·순위는 쓰지 않아요.

> 마지막 업데이트: 2026-11-05 · 기준 문서: `영양제_분류_필터링_기준(1105).pdf` (v3.4)

## 실행 방법

```
cd 분류_필터링
python -m pip install -r requirements.txt
python 전체_실행.py
```
마지막 줄에 `9단계 완료: … 제품 2,227개`가 나오면 정상이에요. 결과는 `output/web_products.csv`에 저장돼요.
필요한 입력 파일(`메인.csv`, `성분별_영양제_제품목록(최종).xlsx`)은 구글 드라이브에서 받아 이 폴더나 바탕화면 `분류 및 필터링 작업에 필요한 최종 파일들`에 두면 돼요.

## 지키는 원칙

- 처방이 아니라 제안. 질환·복용약·임신이면 제품을 보여 주지 않고 전문가 상담 안내
- 일반·전문 의약품은 다루지 않음
- 가격·판매처·브랜드·판매 순위는 쓰지 않음. 점수는 내부에서만 쓰고 공개하지 않음
