| 항목 | 내용 |
|---|---|
| 무엇 | 식약처 **건강기능식품 품목제조 신고사항 (C003)** |

**주요 열**

| 열 이름 | 뜻 |

| `RAWMTRL_NM` | 원재료 (부형제까지 섞여 있어 성분 판단에는 보조로만 사용) |
| `STDR_STND` | 기준규격 (표시량, 함량 추출에 사용) |
| `NTK_MTHD` | 섭취방법 (1일 섭취 개수) |
| `IFTKN_ATNT_MATR_CN` | 섭취 시 주의사항 |
| `PRDT_SHAP_CD_NM` | 제형 (정제, 캡슐 등) |
| `POG_DAYCNT` | 유통기한 |
| 그 밖 | `LCNS_NO`(인허가번호), `DISPOS`(성상), `CSTDY_MTHD`(보관방법), `SHAP`(형태), `CRET_DTM`·`LAST_UPDT_DTM`(생성·수정일) |

- 2004년부터의 **신고 목록**이라 지금 팔지 않는 제품도 들어 있어요. 분류에는 2022년 이후 신고분만 썼어요.
- 제품명에 '수출'이 있는 수출 전용 제품도 섞여 있어요.

| 분류 근거 | 이 시트에 넣은 이유 (예: 기능성 [성분] 표시, 식약처 문구) |
| 가이드 성분 수 | 17개 성분 중 몇 개가 들어 있는지. 1이면 단일 성분 제품 |

| 수입 여부 | 수입 제품인지 |
| 기능성 | 식약처 기능성 문구 원문 |
| 섭취 시 주의사항 | 제품 표시 문구 원문 |

**사용 시 주의**
- `함량`은 **1일 섭취량 기준이 아니에요.** 표시량이 "함량 / 기준 중량" 형식(예: 500mg/1,200mg)이라 1일 섭취량으로 바꾸는 작업이 필요해요 (예정).
- 함량은 내부 필터용이에요. 결과 화면에서 "하루 몇 mg 드세요" 같은 복용 지시로 쓰지 않아요.
- 자동 규칙으로 분류해서 일부 오분류가 있을 수 있어요. 발표 예시로 쓸 제품은 `기능성` 칸을 한 번 확인해 주세요.
- 가격 정보는 없어요. 홍보성을 피하려고 가격은 쓰지 않기로 했어요.
- 인(P)은 영양제로 안내하지 않아서 시트가 없어요.

## 3. `분류_정확도_확인표.xlsx` ✅

제품을 단일·목적형·종합비타민으로 자동 분류한 결과가 맞는지, **무작위 100개를 AI(Claude)가 하나씩 검토**한 파일이에요.

| 시트 | 내용 |
|---|---|
| 안내 | 표본 뽑는 법, 판정 기준 |
| 확인표 | 100개 제품의 분류 결과와 AI 판정 (맞음/틀림/애매), 판단 근거, 원인 |
| 결과 | 정확도, 풀별 결과, 틀린 원인 정리 |

**결과 (보완 전 기준)**
- 맞음 85 · 틀림 6 · 애매 9
- 정확도 **93.4%** (맞음 ÷ (맞음 + 틀림)), 엄격한 정확도(애매를 틀림으로) **85.0%**
- 풀별: 단일 97.9% · 목적형 86.7% · 종합비타민 92.9%
- 표본: 단일 50%, 목적형 35%, 종합비타민 15%, 시드 2026

> AI 판정이라 발표할 때는 "AI 검토 기준, 표본 100개"라고 밝혀 주세요. 틀린 6개와 애매한 9개는 이후 분류 규칙에 반영했어요(19개 중 17개 해결). 보완 후 정확도는 다시 재야 해요.
