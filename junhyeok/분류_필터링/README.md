## 실행 방법

필요한 파일: `메인.csv`, `성분별_영양제_제품목록(수출 제외).xlsx` (이 폴더 → 바로 위 `junhyeok` 폴더 → 바탕화면 `영양제품 자료` 순서로 찾아요). 1단계는 최종본 엑셀이 이 폴더나 바탕화면 `분류 및 필터링 작업에 필요한 최종 파일들`에 있으면 돼요.

```
python -m pip install -r requirements.txt
python 입력엑셀_최종본_만들기.py
python 1단계_기본거르기.py
```
단계는 순서대로 실행해요. 각 단계는 앞 단계 결과를 읽어요.
결과 엑셀은 이 폴더에 생겨요 (깃허브에는 올라가지 않음). 엑셀 저장에 1~3분 걸리니 중간에 키를 누르지 마세요.

| 파일 | 역할 |
|---|---|
| `공통.py` | 모든 단계가 같이 쓰는 설정 (파일 위치, 대상 키워드, 질환 단어, 기준 목록, 엑셀 저장) |
| `requirements.txt` | 필요한 패키지 (pandas, openpyxl) |
| `.gitignore` | 중간 파일(.pkl)이 올라가지 않게 막음 |

## 지키는 원칙

- 영양제는 **처방이 아니라 제안**. 약 복용·임신 등이면 제품을 보여 주지 않고 전문가 상담 안내
- 일반·전문 의약품은 다루지 않음
- 가격·판매처·브랜드·판매 순위는 쓰지 않음 (홍보성 방지)
- 모델의 '위험 높음'은 부족량이나 필요 용량이 아님
