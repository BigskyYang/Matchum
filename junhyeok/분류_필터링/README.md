## 실행 방법

필요한 파일: `메인.csv`, `성분별_영양제_제품목록(수출 제외).xlsx` (이 폴더 → 바로 위 `junhyeok` 폴더 → 바탕화면 `영양제품 자료` 순서로 찾아요). 1단계부터는 최종본 엑셀이 이 폴더나 바탕화면 `분류 및 필터링 작업에 필요한 최종 파일들`에 있으면 돼요.

```
python -m pip install -r requirements.txt
python 입력엑셀_최종본_만들기.py
python 1단계_기본거르기.py
python 2단계_성분확인.py
python 3단계_목적충돌.py
python 4단계_풀나누기.py
python 5단계_웹제품군.py
python 6단계_1일환산.py
python 7단계_상한거르기.py
python 8단계_품질거르기.py
python 9단계_점수.py
```
**한 번에 돌리기 (추천)**: `python 전체_실행.py` → 1단계부터 있는 단계까지 순서대로 실행해요. 입력 엑셀부터 다시 만들려면 `python 전체_실행.py 최종본`.

단계는 순서대로 실행해요. 각 단계는 앞 단계 결과(`.pkl`)를 읽어서, **중간 단계만 다시 돌리면 예전 결과가 섞일 수 있어요.** 코드가 바뀌면 `전체_실행.py`로 처음부터 돌려 주세요. 결과 엑셀은 이 폴더에 생기고 깃허브에는 올라가지 않아요. 저장 중에는 키를 누르지 마세요.

| 파일 | 역할 |
|---|---|
| `공통.py` | 모든 단계가 같이 쓰는 설정 (파일 위치, 대상 키워드, 질환 단어, 기준 목록, 엑셀 저장) |
| `requirements.txt` | 필요한 패키지 (pandas, openpyxl) |
| `.gitignore` | 중간 파일(.pkl)이 올라가지 않게 막음 |

## 지키는 원칙

- 영양제는 **처방이 아니라 제안**. 약 복용·임신 등이면 제품을 보여 주지 않고 전문가 상담 안내
- 일반·전문 의약품은 다루지 않음
- 가격·판매처·브랜드·판매 순위는 쓰지 않음 (홍보성 방지). 점수는 내부 차등에만 쓰고 공개하지 않음
- 모델의 '위험 높음'은 부족량이나 필요 용량이 아님
