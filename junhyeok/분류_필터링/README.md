# 영양제 분류·필터링 (박준혁)

식약처 건강기능식품 데이터(C003)를 **「영양제_분류_필터링_기준(1105).pdf」**에 따라 단계별로 분류·필터링하는 코드예요.
결과는 개인별 영양제 **제안**(처방 아님)에 쓰이는 제품 정보예요. 쉬운 설명은 [분류_필터링_설명.md](분류_필터링_설명.md)를 보세요.

> 이 폴더에는 **코드만** 올려요. 원본 데이터(`메인.csv`)와 결과 엑셀은 팀 규칙에 따라 구글 드라이브로 공유해요 → [드라이브 폴더](드라이브_링크_넣기)

## 용어
- **영양제**: 웹에서 보여 줄 11종 (비타민 B군·C·D, 칼슘, 마그네슘, 아연, 철, 엽산, 식이섬유, 종합비타민 균형형·피로회복형). 이 코드의 1~9단계 결과
- **생활기능 영양제**: 주 목적이 유산균·오메가3·루테인·밀크씨슬인 제품. 5단계에서 따로 보관하고 나중에 다룸
- 두 쪽에 **같은 제품이 겹치지 않고**, 영양제 안에서도 **한 제품은 한 칸에만** 들어가요 (11-05)

## 단계별 핵심 규칙

**1단계 대상 판별** (제품명 키워드, 어린이 → 임산부 → 시니어 → 남녀 공용 → 남성/여성 순서)
- 어린이: 키즈·어린이·주니어·유아·아기·베이비·앙팡·우리 아이 + 성장·쑥쑥·키튼·함소아 + 어린이 브랜드(아이마음·아이누리·아이꼬야·아이사랑·아이튼튼·올키·베투키 등)·캐릭터(뽀로로·티니핑·번개맨)·베베·키드·차일드·토들러·청소년·틴즈·리틀·키 성장(키업·키움·HT042·아이업·키온·키모와·꿈키우다 등)·어린이 젤리·팝핑캔디(코코비타민·코코칼슘·폴리케어·팝핑, 스트레스·다이어트 팝핑 제외). '아이' 한 글자는 아이오딘·아이언·아이케어와 겹쳐서 안 씀
- 임산부·수유부: 임산부·임신·수유·산모 + 맘(슬림맘·라인맘 제외)·마더·프레그·퍼틸(임신 준비)·태아
- 시니어: 실버·시니어 + 50+·60+·50대·60대·50플러스·중장년·어르신·부모님 (마그네슘 350+ 같은 함량 숫자는 제외, '백세'는 대상 연령으로 보지 않음)
- 남성: 남성·맨 + 붙여 쓴 포맨·맨즈·맨에너지 / 여성: 여성·우먼·레이디
- 남녀 공용: 남성·여성이 함께 있거나 남녀·공용·커플이면 일반. 패밀리·온가족·우리가족 제품도 일반 (11-05 결정)

**1단계 판매 안 할 가능성이 높은 제품** (단종 최대한 거르기): 제품명 괄호 안 국가명(미국·캐나다·일본·호주·유럽 등, '브라질산' 같은 원산지 제외)은 해외 판매용으로 제외. C003에는 판매 중 정보가 없어서 완전히 거를 수는 없음

## 실행 방법

필요한 파일: `메인.csv`, `성분별_영양제_제품목록(수출 제외).xlsx` (이 폴더 → 바로 위 `junhyeok` 폴더 → 바탕화면 `영양제품 자료` 순서로 찾아요). 1단계부터는 최종본 엑셀이 이 폴더나 바탕화면 `분류 및 필터링 작업에 필요한 최종 파일들`에 있으면 돼요.

```
python -m pip install -r requirements.txt
python 입력엑셀_최종본_만들기.py
python 1단계_기본거르기.py
python 2단계_성분확인.py
python 3단계_목적충돌.py
python 4단계_풀나누기.py
python 5단계_웹제품군.py
python 6단계_1일환산.py
python 7단계_상한거르기.py
python 8단계_품질거르기.py
python 9단계_점수.py
```
**한 번에 돌리기 (추천)**: `python 전체_실행.py` → 1단계부터 있는 단계까지 순서대로 실행해요. 입력 엑셀부터 다시 만들려면 `python 전체_실행.py 최종본`.

단계는 순서대로 실행해요. 각 단계는 앞 단계 결과(`.pkl`)를 읽어서, **중간 단계만 다시 돌리면 예전 결과가 섞일 수 있어요.** 코드가 바뀌면 `전체_실행.py`로 처음부터 돌려 주세요. 결과 엑셀은 이 폴더에 생기고 깃허브에는 올라가지 않아요. 저장 중에는 키를 누르지 마세요.

| 파일 | 역할 |
|---|---|
| `공통.py` | 모든 단계가 같이 쓰는 설정 (파일 위치, 대상 키워드, 질환 단어, 기준 목록, 엑셀 저장) |
| `requirements.txt` | 필요한 패키지 (pandas, openpyxl) |
| `.gitignore` | 중간 파일(.pkl)이 올라가지 않게 막음 |

## 지키는 원칙

- 영양제는 **처방이 아니라 제안**. 약 복용·임신 등이면 제품을 보여 주지 않고 전문가 상담 안내
- 일반·전문 의약품은 다루지 않음
- 가격·판매처·브랜드·판매 순위는 쓰지 않음 (홍보성 방지). 점수는 내부 차등에만 쓰고 공개하지 않음
- 모델의 '위험 높음'은 부족량이나 필요 용량이 아님
