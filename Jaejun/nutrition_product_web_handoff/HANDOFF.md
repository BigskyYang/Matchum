# 웹개발자 전달 사항

확정된 9단계 제품 목록을 기존 개인 결과의 선정 영양소에 연결함. 영양 예측 모델은 현재 웹 구현을 유지함.

1. `data/nutritionProducts.json`과 `src/productBridge.mjs`를 웹 소스에 추가함.
2. 현재 웹에서 고른 영양소 ID 배열을 `selectedNutrientIds`에 넘김. High 등급에서 새로 선택하거나 확률을 평균하지 않음.
3. 원본 대상값을 `target`에 넘김. 현재 별도 대상 정책이 없다면 기본값 일반으로 목록을 호출함.
4. 반환된 `groups` 순서로 영양소 탭을 표시하고 각 탭 `items`를 카드로 표시함.
5. 기본 페이지 크기는 20개. 페이지 변경 시 `pages[category_id]`를 바꿔 다시 호출함. 제형 선택 시 `filters[category_id].forms`를 넘기고 페이지를 1로 초기화함.
6. 점수·상중 등급은 표시하지 않음. 제품 특징과 원문 정보만 제공함.
7. 비타민 D·종합비타민은 별도 일반 정보/대안 영역 정책을 적용할 때만 명시적으로 요청함. 식품 안내 전용 영양소에는 제품을 붙이지 않음.

## 인수 확인

- 칼슘만 선정: 일반 대상 334개, 첫 페이지 20개, 17페이지가 표시됨.
- B1·B2 동시 선정: B군 탭 한 개만 생김.
- 나트륨만 선정: 제품 탭 없이 기존 식습관 안내를 유지함.
- 서로 다른 탭에 같은 제품이 있어도 제품 저장·비교에서 신고번호를 공통 키로 사용함.
- 제형 필터 적용 후 개수와 페이지를 갱신하고 원본 제품 순서를 유지함.
- D는 자동 부족 예측 결과로 표시되지 않음.
- 모델 원본 확률·등급·선정 정책이 변경되지 않음.

CSV의 상·중 등급은 제품 담당자의 점수 등급이며, 모델의 영양소 위험등급과 별개임. 목록 순서는 담당자가 제공한 것으로, UI에서는 1위·베스트 등의 표기를 추가하지 않음.
