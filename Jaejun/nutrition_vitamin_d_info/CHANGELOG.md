# 변경 기록

## v1.2.0

- 사용자 응답의 활용 가치를 먼저 전달하도록 결과 순서를 개편함.
- 생활 특징별 제목·설명·다음 행동을 guidance에 추가함.
- 외출 장면에 따라 식품 또는 야외활동 정보의 버튼 순서를 조정함.
- 한계 설명은 짧은 보조 문구로 유지함.
- 설문 4문항과 응답값은 v1.1.0과 동일함.
- 제품 정보 접근은 모든 응답에서 동일하며 자동으로 열지 않음.
- 기존 영양예측 모델·점수·제품 필터링에는 변경 없음.

## v1.1.0

음식·시간 계산 질문을 제거하고 출퇴근/점심/운동/휴일 생활 4문항으로 교체함.
