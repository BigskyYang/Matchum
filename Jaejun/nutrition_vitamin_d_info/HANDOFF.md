# 웹 개발자 전달 사항

## 추가 위치

개인 영양예측 결과와 구분되는 ‘비타민 D 생활·식사 정보’ 영역에 추가함. 머신러닝 예측 영양소 목록, 위험 등급, 최대 5개 선정 결과에는 합치지 않음. 모델 입력 18개/7개에 새 필드를 넣지 않음.

## 입력 계약

config/survey.ko.json의 영문 value를 사용함. 화면 라벨을 값으로 전달하지 않음. 미응답은 필드를 생략하거나 null로 전달함. 빈 배열·빈 문자열을 미응답 대신 전달하지 않음. 함수는 알 수 없는 키와 값을 거부함.

- outdoor_days=none 또는 미응답이면 시간 문항을 숨기고 값을 비움. 함수도 남은 유효 시간값을 요약에서 제외함.
- 일정하지 않음은 활동 없음으로 바꾸지 않음.
- 시간 모름은 0분으로 변환하지 않음.
- 식품의 none/unknown은 다른 선택지와 동시 선택할 수 없음.
- 전체 선택 문항이며 건너뛰어도 기존 개인 결과와 일반 정보 탐색이 동작해야 함.
- 나이·월·위치 정보를 별도로 받거나 등급 보정에 사용하지 않음.

## 기존 식품 응답 재사용

실제로 먹는다고 확인된 생선/달걀 응답은 사용자에게 재사용 사실을 보여주고 수정 가능하게 제안할 수 있음. 빈도가 0이 아니라는 이유로 자동으로 확정하지 말고, 미응답·모름을 먹지 않음으로 바꾸지 않음. ‘달걀’ 응답만으로 노른자 섭취 여부를 확정하지 않음. 생선·해산물 묶음 응답만으로 생선 섭취를 확정하지 않음. 유제품을 먹는다고 강화식품으로 분류하지 않음. 기존 질문으로 구분되지 않으면 새 문항에서 직접 확인함.

## 결과 렌더링

summaryCards의 문구를 그대로 사용하고, 3개 notices를 결과 가까이에 표시함. 미응답은 emptyMessage로 설명함. 부분 응답도 표시하되 미응답을 추정하지 않음. 빨강·초록 상태 표시, 위험도 막대, 개선/악화, 충분/부족 등급을 추가하지 않음.

## 제품 버튼

product_information 버튼은 항상 기본 접힘 상태이며 클릭할 때만 기존 비타민 D 일반 정보 목록을 요청함. 콜백 예시:

```js
function onVitaminDProductClick(info) {
  const action = info.actions.find(x => x.id === 'product_information');
  openGeneralVitaminDProducts(action.nutrientId);
}
```

openGeneralVitaminDProducts는 웹 담당자가 기존 제품 목록에 연결하는 함수임. nutrientId='vitamin_d'는 이 모듈의 논리 ID임. 실제 기존 카탈로그 ID 및 제품 연결 API와 대조해 매핑함. 본 모듈은 기존 제품 API를 직접 호출하지 않으므로 붙여 넣기만으로 원격 연결까지 완료되는 구조가 아님.

기존 D 목록의 정렬·필터·기본 페이지 크기 20개를 유지하고 새 순위는 만들지 않음. 야외활동·식품 응답에 따라 목록·순서·버튼 접근성을 바꾸지 않음. 표시 제품 모두를 개인에게 적합하거나 필요하다고 설명하지 않음.

## 인수 확인

- 설문을 건너뛰어도 기존 예측과 일반 D 정보 탐색이 가능함.
- 0일이면 시간 질문이 숨겨지고 이전 시간이 결과에 남지 않음.
- 모름이 없음으로 표시되지 않음.
- 응답을 바꿔도 기존 영양소 확률·등급·선정 목록은 바뀌지 않음.
- 새 설문 결과는 습관 변화 시뮬레이터의 예측 변수로 넣지 않음.
- 어떤 응답이든 D 제품 정보는 자동으로 열리지 않고 클릭으로만 열림.
- 실제 웹 화면·기존 제품 연결 테스트는 웹 담당자가 수행함.
