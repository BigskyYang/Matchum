# 웹 개발자 전달 사항 v1.2.0

## 이전 버전에서 변경

v1.1.0에서 업데이트할 경우 설문/응답을 유지하고 결과 코드와 화면 렌더링을 교체함. 아래 입력 변경은 v1.0.0에서 이전하는 경우에만 해당함. 설문을 음식 질문 없는 생활 4문항으로 교체함. 함수 이름 buildVitaminDInfo는 유지하지만 입력 필드는 변경됨.

삭제: outdoor_days, outdoor_duration, vitamin_d_foods.
추가: commute, lunch_outing, exercise_setting, day_off_outing.

이전 저장 응답을 새 응답으로 추정 변환하지 않음. 비타민 D 응답 상태만 버전별로 분리하거나 초기화함. 기존 개인 영양 설문·결과는 유지함. 식품 문항/기존 FFQ 응답을 이 모듈에 전달하지 않음. 알 수 없는 필드는 오류를 반환함.

## 입력

config/survey.ko.json의 value를 사용함. 모두 단일 선택·선택 문항이며 조건부 후속 문항은 없음. 미응답은 생략 또는 null. 모름·일정하지 않음은 각 문항의 unknown이며 활동 없음과 다르게 표시함. 재택/정기 이동 없음은 출퇴근이 없다는 뜻일 뿐 야외활동 없음으로 해석하지 않음.

## 결과

guidance.headline → guidance.summary → guidance.nextStep → actions → notices 순서로 표시함. summaryCards는 응답 상세를 펼치는 선택 영역에서만 사용하며 guidance와 같은 문구를 본문에 중복 표시하지 않음. 이동수단을 실제 햇빛 노출 시간으로 환산하거나 답변을 합쳐 좋음/보통/나쁨을 만들지 않음. 짧은 notices 문구는 결과 가까이에 보조 글씨로 표시하되 숨기거나 클릭해야만 보이게 하지 않음. 제품 버튼은 모든 응답에서 마지막 보조 행동으로 제공함. 첫 두 정보 버튼 순서는 guidance.primaryActionId를 따름. 각 버튼은 foodInformation/outdoorInformation/기존 제품 목록을 실제로 열도록 연결함.

foodInformation은 공통 식품 설명임. 식품 섭취 질문이 아님. 기존 개인 예측 결과의 높은 편 목록이나 최대 5개에 비타민 D를 추가하지 않음. 새로운 설문은 기존 모델과 습관 시뮬레이터의 입력에 전달하지 않음.

## 제품 목록 연결

product_information 클릭 시 기존 비타민 D 일반 제품 정보를 열도록 웹에서 콜백을 구현함. nutrientId=vitamin_d는 논리 ID이므로 기존 카탈로그 ID와 대조해 매핑함. 모델이 선정한 개인 추천으로 표시하지 않음. 기존 목록·정렬·필터·기본 페이지 크기 20개 유지.

```js
function onVitaminDProductClick(info) {
  const action=info.actions.find(x=>x.id==='product_information');
  openGeneralVitaminDProducts(action.nutrientId);
}
```

openGeneralVitaminDProducts는 웹 담당자가 기존 제품 목록에 연결하는 함수임. 실제 원격 연결은 이 ZIP에서 수행하지 않음.

## 인수 확인

- 4문항 모두 음식·섭취량·분 단위 계산을 요구하지 않음.
- 재택, 운동 안 함, 모름을 서로 구분함.
- 미응답으로도 일반 정보와 명시적 제품 탐색 가능.
- 어떤 응답에서도 부족/충분·위험 등급과 햇빛 확보량을 만들지 않음.
- 제품은 클릭 전 접힘이며 응답에 따른 자동 노출이나 우선순위 변경 없음.
- 기존 영양 모델의 확률·등급·선정 결과가 달라지지 않음.
- 실제 UI 및 제품 ID 연결 검증은 웹 담당자가 수행함.

## 표시 분기 우선순위

1. 낮 야외운동 응답: 해당 생활 특징과 야외활동 정보 우선
2. 쉬는 날 낮 외출 자주: 해당 생활 특징과 야외활동 정보 우선
3. 점심 외출 거의 매일: 해당 생활 특징과 야외활동 정보 우선
4. 점심 외출 드묾 + 쉬는 날 낮 외출 드묾 + 실내운동/운동 없음: 두 외출 장면을 짚고 식품 정보 우선
5. 그 외 확인된 생활 응답: 생활 장면 요약과 식품 정보 우선
6. 전체 미응답/주요 항목 모름: 일반 안내. 출퇴근 응답만으로 야외활동을 추정하지 않음

서로 다른 응답이 섞여도 원 응답 요약은 그대로 보존함. 분기 키는 내부 화면 제어용으로 사용자에게 상태/위험 등급처럼 표시하지 않음.
