# 결과 표시 정책 v1.2.0

## 화면 순서

1. guidance.headline: 응답에서 확인된 생활 특징
2. guidance.summary: 점심·운동·쉬는 날 응답의 근거 요약
3. guidance.nextStep: 먼저 확인할 정보
4. actions: 상황에 따라 식품 또는 야외활동 정보 우선, 제품 정보는 항상 마지막
5. notices: ‘생활 응답에 따른 참고 안내이며, 비타민 D 상태를 측정한 결과는 아니에요.’를 작은 보조 문구로 표시함

기존의 긴 한계 문구를 첫 결과로 표시하지 않음. 원 응답 상세는 summaryCards로 선택 제공하며 본문과 중복 표시하지 않음. 정보 버튼을 누르면 각 정보 내용을 읽을 수 있어야 함.

## 분기 의미

응답에 맞는 정보의 순서를 정하는 규칙임. 모든 분기는 점수·순위·비타민 D 위험 등급이 아님. 점심·휴일 외출이 드물다는 응답은 해당 장면에 한정하여 표현하고 하루 전체의 노출이 적다고 단정하지 않음. 낮 야외운동/자주 외출도 충분한 비타민 D 확보를 의미하지 않음. 출퇴근 방식만으로 노출을 판정하지 않음. 운동 없음과 모름은 다르게 처리함.

## 정보와 제품

식품 질문을 새로 묻거나 기존 식품 응답을 가져오지 않음. 식품 일반 정보만 제공함. 낮 활동이 확인되면 야외활동 시 참고할 점을 먼저 보여주고 자외선 보호를 안내함. 햇빛 노출을 늘리라는 행동이나 시간 목표를 만들지 않음. 모든 사용자는 동일한 제품 목록에 명시적으로 접근할 수 있으며 기본 접힘 유지. 제품이 필요하다는 표시나 상태 예측은 없음.
