# 로컬 검증 기록

2026-11-05. Node.js v24.22.1에서 9개 테스트 통과.

- 전체 미응답과 부분 응답 구분
- 활동 없음에서 숨겨진 시간의 잔존값 제외
- 모름/없음 구분
- 복수 식품 선택 정렬과 입력 불변성
- 배타 응답·중복·잘못된 코드 거부
- 완전 응답 189가지 조합에서 예측 등급 없이 결과 생성
- 모든 조합에서 제품 정보 기본 접힘과 사용자 클릭 조건 유지
- 같은 입력에서 같은 결과 반환

모든 JSON 파일을 파싱하여 형식을 확인했고 예시 출력은 실제 함수 실행으로 생성함. ZIP 파일 구조와 CRC를 확인함.

검증하지 않은 범위: 원격 웹 화면, 기존 제품 카탈로그 ID 매핑, 기존 모델과의 실시간 통합, 사용자 임상/영양 효과. 기존 모델 파일·데이터는 포함하지 않았으며 변경하지 않음.
