# 로컬 검증 v1.2.0

2026-11-05. Node.js에서 테스트 12개 통과. 완전 응답 400가지 조합 확인.

- 기존 가벼운 선택 4문항 유지, 식품 질문/시간 계산 없음
- 전체/부분 미응답과 모름/활동 없음 구분
- 외출이 드문 장면과 낮 야외운동의 안내 분기
- 점심/휴일 외출이 드물어도 낮 야외운동 응답은 별도로 보존
- 출퇴근 응답만으로 야외활동/영양 상태를 추정하지 않음
- 생활 특징 → 근거 응답 → 다음 행동 → 버튼 → 짧은 보조 문구 순서
- 정보 버튼이 참조할 식품/야외활동 정보 제공
- 제품 접근 조건과 기본 접힘 유지, 점수/위험등급/복용량 생성 없음
- 잘못된 값과 이전 v1.0.0 필드 거부, 입력 불변성·재현성

예시 결과 5종을 실제 함수 실행으로 생성함. 모든 JSON 파싱과 ZIP CRC 확인.

범위: 로컬 코드와 전달 명세 검증임. 원격 웹 화면·카탈로그 ID 매핑·기존 모델 통합·비타민 D 예측 성능·건강 개선 효과는 검증하지 않음.
