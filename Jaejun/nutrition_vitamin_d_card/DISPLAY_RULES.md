# 응답 조합 해석

모든 분기는 생활 장면 해석용임. 비타민 D 상태/합성량/복용 필요성의 등급이 아님. 앞에서부터 조건을 적용함.

| 조건 | 해석 중심 |
| --- | --- |
| 점심 드묾 + 휴일 드묾 + 낮 야외운동 | 운동이 응답 장면의 주요 낮 활동 접점 |
| 점심 드묾 + 휴일 드묾 + 실내/운동 없음 | 여러 생활 장면에서 낮 외출 기회가 제한적 |
| 점심 드묾 + 휴일 드묾 + 아침·저녁·밤 야외운동 | 야외운동 여부와 낮시간 접점을 구분 |
| 점심 드묾 + 휴일 자주 + 낮 야외운동 아님 | 두 외출 장면에서는 쉬는 날 접점이 두드러짐 |
| 점심 자주 + 휴일 드묾 | 두 외출 장면에서는 점심의 반복 접점 |
| 점심 자주 + 휴일 자주 | 두 장면에 걸쳐 접점이 나타남 |
| 그 외 낮 야외운동 | 운동을 통한 접점 |
| 그 외 점심/휴일 자주 | 확인된 외출 장면 |
| 그 외 알려진 주요 응답 | 상황별 차이를 설명하고 식품 공급 경로 안내 |
| 주요 항목 모두 미응답/모름 | 개인화 D 카드 없음 |

알려지지 않은 운동 응답을 실내/운동 없음으로 처리하지 않음. 출퇴근 응답만으로 낮 활동을 판정하지 않음. 휴일이 평일을 보충한다는 양적 결론, 햇빛으로 충분하다는 결론, 제품이 필요하다는 결론을 만들지 않음. 근거 코드가 reason.evidence에 남아 화면 설명과 대조 가능함.

식품 정보와 제품 목록은 모든 생성 카드에서 기존 영양소와 같은 구성으로 제공함. 응답에 따라 제품의 적합성이나 순위를 변경하지 않음. 보조 note는 읽을 수 있게 남기되 카드의 첫 답변으로 앞세우지 않음.
