# 최종 피드백 반영 패치 검증

2026-11-04 · 어댑터 v1.4.1-web-feedback / 가중치 v1.4-web-retrained

- 회귀·추론·표시 규칙 테스트21개 통과.
- 현재 흡연 유무의 0/1 변환과 기존 흡연량 입력 유지 확인.
- 강도 구분 없는 주150분 통합 응답의 0/1 변환 확인.
- 규칙적 수면 5:2 평균, 불규칙 수면 직접 평균 두 경로 확인.
- 두 기준이 다를 때 평소 식사 등급 우선, 미제공 시 생활습관 등급 사용 확인.
- 표시 객체의 영양소별 결과에 확률 숫자가 없음을 확인. API 원시 확률은 유지함.
- 최대5개·중복·유효ID 검사 및 웹에서 제공한 순서 유지 확인. 기본 영양소 순위를 새로 만들지 않음.
- 모델24개·고정등급JSON2개의 SHA-256이 v1.4와 모두 동일함.
- v1.4 예시와 대응하도록 바꾼 원시설문에서 모델입력18개가 전부 같고 영양확률·등급24개가 모두 동일함.
- 가중치 버전과 어댑터 버전을 분리함. 이번 변경으로 가중치 재export는 필요하지 않음.

팀원이 보고한 웹60명 1e-8 검증은 이번 패치에서 재실행하지 않음. 실제웹화면·원격저장소·노션페이지 수정은 수행하지 않음. 공식 JSON Schema 검증기로 전체표준검사를 한 결과가 아니며 JSON문법과 요청·응답키·분기 동작을 검사함.

이번 패치는 설문간소화 합의를 구현한 것이며, 기존학습문항과 같은 임상적·통계적 특성을 가진다는 추가 검증은 아님. v1.4의 AUC를 변경된웹질문으로 새로 측정한 성능으로 설명하지 않음.
