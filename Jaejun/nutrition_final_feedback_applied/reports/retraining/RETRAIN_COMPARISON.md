## 평가·등급 정책

- 평가 자료는 학습·확률 보정·파라미터 선택·새 경계값 선택에 사용하지 않음.
- 상대등급은 기존 고정 JSON 경계값을 그대로 사용하여 가중치 정리 효과를 비교함. 등급을 다시 3등분한 버전이 아님.
- 이진 평가 지표용 cutoff는 각 모형의 학습 예측에서만 Youden J로 계산함. 낮음/보통/높음 표시에는 이진 cutoff를 사용하지 않음.
- 이번 정리 대상은 생활습관 14개 모형임. mini-FFQ 10개 가중치·경계는 변경하지 않음.
- 각 영양소의 성능 변화가 모두 같은 방향인 것은 아님. 통계적 유의성·동등성·실제 사용자 효과를 입증한 결과로 해석하지 않음.
- 제외 2명이 영향을 주는 이유는 단순 표본 수뿐 아니라 트리 분할·최적화 경로 변화도 포함할 수 있음.
