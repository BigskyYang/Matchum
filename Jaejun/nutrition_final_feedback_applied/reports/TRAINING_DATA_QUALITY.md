# 과일·채소 99 정리 및 재학습 완료

2026-11-04 · v1.4-web-retrained

## 확인과 처리

원래 완전응답 자료의 2022–2023 학습 대상 9,742명 중 과일·채소에 모름 코드 99가 있는 2명을 학습에서 제외함. 정리 후 9,740명으로 생활습관 모형 14개를 재학습함. 2024년 평가 대상 5,320명에는 해당 99가 없어 전원을 동일하게 유지함.

기존 자료에서 Step6_전체영양성분_TargetMatrix.csv와 초기 src/train.py를 찾아 정답·학습 조건을 복원했음. 원본 모형의 파라미터를 복제하고 원래 9,742명으로 재학습한 14개 모두에서 2024 예측이 원본과 일치함(최대 절대 차이 1e-10 이하, 실제 0). 따라서 같은 정답·특성·순서·설정에서 비정상 코드 정리 효과를 비교함.

새 HGB 모형 13개에서 과일·채소 bin의 유효 범위 밖 경계가 없음을 확인함. 비타민 C도 같은 정리된 학습 행으로 스케일러와 로지스틱 회귀를 다시 학습함. 신규 웹 입력의 99 거부도 유지함.

## 가중치·경계 정책

- 생활습관 모형 14개: 정리 후 재학습 가중치.
- mini-FFQ 모형 10개: 이번 99 입력을 사용하지 않는 별도 자료 모형이므로 원본 유지.
- 두 모듈의 Low/Mid/High 경계: 기존 고정 JSON 원본 유지. 2024를 이용해 새 3등분 경계를 고르지 않음.
- 이진 성능평가 cutoff: 각각 학습 예측에서만 Youden J로 계산함. 사용자 등급 표시에는 사용하지 않음.

정답표의 실제 정답을 사용했으며 모형 예측값을 정답으로 사용하지 않음. 이번 작업은 99 정리 효과의 재현 가능한 비교이며, KDRI 기준표의 공식 원문 대조나 실제 사용자 검증을 새로 완료한 것은 아님.

상세 성능과 등급 변화는 retraining/RETRAIN_COMPARISON.md 참조. 과거 ‘학습자료 미확보·재학습 미완료’라는 v1.3의 제한은 이 버전에서 해소됨.
