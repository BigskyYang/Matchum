# v1.4 재학습 버전 검증 결과

2026-11-04 · Python 3.12 / scikit-learn 1.8.0

- 기존 원본 생활습관 모형 14개를 같은 학습자료·정답·파라미터로 재학습했을 때 2024 예측 최대 절대 차이 0.0 확인.
- 기존 정답표를 ID·연도로 일대일 연결. 정답 재정의나 예측값을 정답으로 사용하는 처리 없음.
- 과일·채소 비정상 코드가 있는 학습 2명 제외 후 9,740명으로 재학습. 평가 5,320명 유지.
- 회귀·추론·등급 경계·학습 수·가중치 유효값·보존 파일 검증 15개 테스트 통과.
- HGB 13개 모형의 과일·채소 bin에 유효범위 밖 경계가 없음을 확인.
- mini-FFQ 10개와 상대등급 경계 JSON 2개가 원본과 동일한 SHA-256인지 확인.
- 새 모델의 원시 설문 경로와 숫자 특성 경로 예측 일치, 19·64세와 65세의 모듈 가용성 검사.
- 새 버전 예시 JSON을 실제 실행으로 생성하고 응답 version·모형 품질 상태·스키마 키 확인.

평가 AUC·Brier와 영양소별 등급 변화는 retraining/RETRAIN_COMPARISON.md 참조. 공식 영양 기준 원문 대조·새 외부자료 검증·웹 원격 배포는 이 검사에 포함되지 않음.
