# 팀 인계 — v1.4 재학습 완료

- 군집 유형 산출·N1~O3 명칭·웹 표시는 군집·웹 담당 영역임. 영양예측은 군집 ID 없이 동작함. 제공한 cluster_hook은 선택 기능이며 우리 모형의 필수 작업이나 미완료 과제가 아님.
- 원래 정답표와 초기 학습 코드를 확보하고, 기존 모형 14개의 예측을 정확히 재현한 뒤 99 포함 학습 2명을 제외하여 재학습함.
- 웹 범위 축소·전처리 방향·월간음주 수정·sklearn 1.8.0 고정은 그대로 적용됨.
- 두 모형의 확률을 평균하지 않음. 생활습관 14개는 새 가중치, mini-FFQ 10개는 원본 가중치임.
- 상대등급 경계 JSON은 기존 값을 유지함. 모델 파일만 교체한 새 버전이므로 웹은 예측확률을 캐시했다면 새 버전 기준으로 다시 계산해야 함.
- 실제 응답 version은 v1.4-web-retrained임. API 응답 경로는 v1.3에서 수정한 확률+등급 구조를 유지함.
- 상세 성능은 reports/retraining/RETRAIN_COMPARISON.md 참조. 이전 버전의 AUC를 현재 생활습관 모형 수치와 혼합하지 않음.
- 웹 저장소 push·원격 배포는 이 패키지 제공 작업에 포함하지 않았음.
