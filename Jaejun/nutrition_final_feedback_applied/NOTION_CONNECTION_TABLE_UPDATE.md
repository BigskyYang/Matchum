# 노션 연결표 교체용 — 최종 피드백 반영

2026-11-04 · 패키지 v1.4.1 / 가중치 v1.4

이 문서는 노션에 붙여넣을 교체 내용임. 실제 노션 페이지를 수정했다는 기록이 아님.

## 현재 코딩 방향

| 입력 | 실제 모형 특성 | 값·변환 |
|---|---|---|
| 현재 흡연 유무 | ML_smoker | 아니오=0, 예=1. 평생 100개비 조건 없음 |
| 하루 흡연량 | ML_cigarettes_day | 기존 수치 입력 유지, 비흡연자는 0 |
| 통합 활동 주150분 이상 여부 | ML_aerobic | 아니오=0, 예=1. 강도 구분·고강도×2 없음 |
| 규칙적 수면 | ML_sleep_hours | (평일 수면시간×5+휴일×2)/7 |
| 불규칙 수면 | ML_sleep_hours | 직접 응답한 평균 수면시간 |
| 나이 | 설명_age | 웹이 전달한 age 그대로 |
| 아침·점심·저녁 | ML_*_freq_ord | 주0회=0, 주1~2회=1, 주3~4회=2, 주5~7회=3 |
| 외식 | ML_eatingout_freq_ord | 거의안함=0, 월1~3회=1, 주1~2회=2, 주3~4회=3, 주5~6회=4, 하루1회=5, 하루2회이상=6 |
| 음주빈도 | ML_drink_freq_ord | 최근1년없음=0, 월1회미만=1, 월1회정도=2, 월2~4회=3, 주2~3회=4, 주4회이상=5 |
| 월간음주 | ML_drink_month | 음주빈도 코드>=2이면1, 아니면0 |
| 1회 음주량 | ML_drink_amount_ord | 최근1년음주없음만0, 월1회미만도 실제 양 코드1~5 유지 |
| 과일·채소 | 식습관_LS_FRUIT / LS_VEG2 | 하루3회이상=1, 하루2회=2, 하루1회=3, 주5~6회=4, 주2~4회=5, 주1회=6, 월2~3회=7, 월1회=8, 거의안함=9 |
| 모름 코드 | 해당 특성 | 99를 값으로 입력하지 않음 |

## 결과·담당 범위

- 생활습관14개, 식품빈도10개를 별도로 유지하고 확률을 평균하지 않음.
- 두 기준이 다르면 화면 대표 등급은 평소 식사 기준을 사용. 미제공이면 생활습관 기준 사용.
- 화면은 높은 편/보통/낮은 편만 표시하고 확률 숫자는 숨김.
- 살펴볼 영양소는 기존 웹 규칙으로 최대5개. 선정·동점 순서는 웹 담당 영역.
- 안내문: ‘기준 자료 안에서의 상대 등급이며, 부족을 진단한 결과가 아니고 필요한 양을 알려주지 않습니다.’
- 영양 모델 패키지에는 제품 경로가 없고, 제품 정보는 준혁 님 파트에서 관리함.
- 군집은 웹에서 별도로 판정하므로 cluster_hook을 사용하지 않음.

## 이전 내용이 남았다면 교체할 문구

- 끼니 ‘1=주5~7회, 4=주0회’ → ‘3=주5~7회, 0=주0회’.
- 외식 ‘1=하루2회이상, 7=거의안함’ → ‘6=하루2회이상, 0=거의안함’.
- 월간음주 ‘빈도>0’ → ‘빈도>=2’.
- 현재 웹 어댑터의 유산소 ‘중강도+고강도×2’ 설명 → ‘통합 활동 주150분 이상 여부’.
- ‘웹 전체에 제품정보 없음’ → ‘영양 모델 패키지에는 제품 경로가 없고 제품 정보는 준혁 님 파트’.

학습자료의 유산소 산출 정의는 과거 분석 기록에 남겨 구분함. 현재 설문 단순화 합의를 과거 학습자료 정의가 바뀐 것처럼 소급해서 설명하지 않음.
