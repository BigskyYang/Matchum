## 모델 버전 전달

이번 변경은 어댑터 v1.4.1이며 학습 가중치는 v1.4 그대로임. 모형24개·상대등급JSON2개의 해시 동일성을 확인함. 따라서 nutritionModels.json의 가중치 재export는 필요하지 않음. 화면 규칙·원시설문 계약·문서만 맞추면 됨.

학습 가중치가 바뀌는 후속 작업에서는 model_version을 올리고 웹 담당자에게 알려 export_nutrition_models.py로 다시 내보내도록 함.

## 설문·검증 구분

흡연·통합 활동·불규칙 수면 입력은 팀 합의된 웹 설문 표현임. v1.4의 AUC는 원래 조사 특성의 평가 결과이며, 이번 합의된 질문 표현의 실제 사용자 성능을 새로 측정한 결과는 아님. 입력18개에 필요한 값이 없으면 임의로 채우지 말고 기존 웹 입력 계약을 확인함.
