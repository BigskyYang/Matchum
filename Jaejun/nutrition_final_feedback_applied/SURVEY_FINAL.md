# 최종 웹 설문 v1.4

웹 구현용 원본은 `config/survey_web.json`, 요청 스키마는 `config/survey_web.schema.json`임.

- 기본정보: 성별·만 나이.
- 생활습관: 흡연·음주·운동·좌식시간·수면·스트레스 인지·끼니·외식·과일·채소.
- mini-FFQ 5문항: 육류 / 생선·해산물 / 달걀 / 콩·두부·콩제품 / 우유·유제품.
- mini-FFQ 공통 응답: 거의 먹지 않음 / 월 1~3회 / 주 1~2회 / 주 3~4회 / 주 5~6회 / 하루 1회 / 하루 2회 / 하루 3회 이상.
- 19~64세에서 5문항 완비 시 식품섭취빈도 모형을 계산함. 65세 이상·5문항 누락은 생활습관 결과만 제공함.
- PHQ-9·대사건강·질환·임신·약물·현재 영양제·제품추천 안전 4문항은 웹에서 수집하지 않음.
- 일반 스트레스 인지 문항은 생활습관 모형 입력이므로 유지함. 우울 점수나 정신건강 평가를 반환하지 않음.
- 운동 시간은 최근 일주일 총량, 좌식시간은 하루 평균으로 질문함.
- 모름을 99나 0으로 바꾸지 않음. 필수 생활습관 문항은 답변 확인을 요청함.
- 술을 마신 적 없는 경우 빈도·양은 0으로 변환. 월 1회 미만은 월간음주=0이지만 1회 음주량은 응답값 유지.

선택형 요청값은 JSON의 `options[].value` 문자열을 사용함. 원시 설문 요청과 숫자 특성 요청을 혼용하지 않음.
