# Research-only full-information model

This folder/model uses `HEI_PROTF` and `HEI_DAIRY`.

These variables are derived from the same-day KNHANES 24-hour recall that is
also used to construct nutrient intake-risk targets. Therefore this model must
NOT be presented as expected web-survey performance.

Use:
- research benchmark
- upper-bound / full-information comparison
- sensitivity analysis

Do not use:
- production inference
- web survey prediction
- product recommendation pipeline
