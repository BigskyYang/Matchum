# 사용자 설문 v4 — 서비스용

기존 설문 v3의 큰 구조는 유지함.

## 영양예측에 직접 사용
- 성별, 나이
- 흡연
- 음주
- 유산소/근력운동
- 좌식시간
- 수면
- 스트레스
- 아침/점심/저녁 빈도
- 외식 빈도
- 과일 섭취빈도
- 채소 섭취빈도(김치·장아찌 제외)

## 설문에는 유지하지만 현재 영양예측에는 직접 사용하지 않음
- 고기·생선·달걀·콩류 섭취빈도(Q25)
- 우유·유제품 섭취빈도(Q26)

이 두 문항은:
1. 사용자 식습관 설명
2. 생활유형/향후 clustering 후보
3. 과거 FFQ 등을 이용한 validation 후 서비스 모델 개선
용도로 유지함.

## 별도 설명 레이어
- PHQ-9: 정신건강 profile
- 고혈압/당뇨/이상지질혈증: metabolic context
- 교대근무: lifestyle context

## 향후
최종 clustering model이 확정되면 동일 설문에서 lifestyle cluster/NBTI를 함께 반환함.
