# 개인 결과 기반 제품 드롭다운 구현 명세

## 확정 동작

1. 이미 구현된 개인 결과에서 선정한 영양소 ID 배열을 `selectedNutrientIds`에 전달함. 전체 14개 출력이나 제품군 전체 목록을 그대로 드롭다운에 넣지 않음.
2. `buildProductResult` 또는 `fromModelResponse` 호출 후 `getNutrientDropdownOptions(result)`로 선택지를 만듦.
3. B1·B2는 비타민 B군 한 항목으로 통합함. 단백질·인·칼륨·비타민 A·나트륨은 기존 식품 안내만 유지하며 제품 드롭다운에서 제외함.
4. 선택한 영양소에 해당하는 목록만 표시함. 기본 제품 순서와 영양소 순서는 담당자가 제공한 기준을 유지함.
5. 비타민 D·종합비타민은 일반 정보/대안 영역에 따로 배치함. 개인 영양소 드롭다운에는 자동 추가하지 않음.

## 예시

개인 결과 선정 ID가 `calcium, magnesium, vitamin_b1, vitamin_b2, sodium_excess`이면 드롭다운은 아래 세 개임.

| 순서 | 화면 라벨 | 값 |
|---|---|---|
| 1 | 마그네슘 | magnesium |
| 2 | 비타민 B군 | vitamin_b |
| 3 | 칼슘 | calcium |

나트륨 안내는 기존 결과 영역에 유지함. 위 예시는 연결 동작을 설명하기 위한 것이며 실제 개인 추론 결과가 아님.

## 화면 문구

| 위치 | 문구 |
|---|---|
| 섹션 제목 | 관련 제품 살펴보기 |
| 설명 | 결과에 연결된 영양소를 선택하고 제품별 특징을 비교해 보세요. |
| 영양소 드롭다운 제목 | 살펴볼 영양소 |
| 선택 전 안내 | 영양소를 선택해 주세요 |
| 목록 제목 | {영양소명} 관련 제품 |
| 개수 | 제품 {개수}개 |
| 검색창 | 제품명 검색 |
| 초기화 | 필터 초기화 |
| 적용 버튼 | 제품 {개수}개 보기 |
| 상세 펼치기 | 성분·기능성·주의사항 보기 |
| 필터 결과 없음 | 선택한 조건에 해당하는 제품이 없습니다. 필터를 변경해 주세요. |
| 연결 항목 없음 | 이번 결과에 연결된 제품 목록이 없습니다. 식품 안내를 확인해 주세요. |
| 해당 대상 제품 없음 | 해당 대상에 등록된 제품이 없습니다. |

영양소 드롭다운에는 ‘전체 영양소’를 기본 선택지로 넣지 않음. 해당 사용자의 연결 목록 안에서만 이동함. 원본 대상에 후보가 없는 항목은 비활성 상태로 표시하고, 원본에 없는 제품이나 대상 대체 목록을 임의 생성하지 않음.

## 추가 필터의 한국어 옵션

전체 마스터 라벨과 데이터 매핑은 `config/dropdown_labels.ko.json`에 있음. 아래 옵션 중 선택 영양소·대상에 실제 후보가 존재하는 항목만 제공함.

| 제목 | 선택지 | 데이터 |
|---|---|---|
| 제품 구성 | 전체 / 단일 영양소 중심 / 목적형 복합 / 종합비타민 | source_product_type |
| 제형 | 전체 / 정제 / 캡슐 / 분말 / 액상 / 젤리 / 과립 / 환 / 겔 / 바 / 기타 | form |
| 하루 섭취 개수 | 전체 / 1개 / 2개 / 3개 / 4개 이상 | intake_label에서 파생 |
| 제품 대상 표시 | 전체 / 일반 / 남성 / 여성 / 시니어 | target |
| 종합비타민 유형 | 전체 / 균형형 / 피로·활력형 | multi_balance / multi_energy |
| 1일 섭취량당 함량 | 최소 / 최대 | daily_amount 및 daily_unit |

- ‘단일’에는 보조 성분이 포함될 수 있으므로 화면은 ‘단일 영양소 중심’으로 표시함.
- 목적형 복합은 `source_product_type`이 ‘목적형’으로 시작하는 행을 모두 포함함.
- 제형 ‘정’은 ‘정제’, ‘기타(당류 포함)’는 ‘기타’로 표시함.
- 하루 섭취 개수는 현재 별도 숫자 필드가 아님. 정·캡슐·포·병 등 식별 가능한 개수에 적용하고, g·mL처럼 중량·부피로만 적힌 값이나 미해석값은 ‘전체’에서 유지함. 1g을 1개로 바꾸지 않음.
- 함량 범위는 같은 영양소·같은 단위 안에서만 비교함. 빈 함량을 0으로 바꾸지 않음.
- 제품 대상 필터는 기존 웹 대상 정책으로 허용된 풀 안에서만 적용함. 정책상 대상이 하나라면 해당 필터를 숨겨도 됨. 여러 대상은 원본 순서의 비교 범위가 다르므로 대상별 섹션을 유지함.
- 종합비타민 유형 선택은 별도 일반 정보/대안 영역에서만 표시함.
- 상·중 제품 점수 등급, 모델 확률, 베스트·추천순위는 필터 선택지에 넣지 않음.

## 상태 및 페이지 처리

- 최초에는 활성화된 첫 영양소를 선택함. 새 개인 결과에서 기존 선택 영양소가 사라지면 활성 첫 항목으로 변경함. 모두 없으면 제품 목록을 숨기고 안내 문구를 표시함.
- 최초 페이지 크기는 20개. 12~20개 범위에서 변경 가능함.
- 영양소 또는 필터를 변경하면 해당 목록 페이지를 1로 초기화함.
- 필터는 전체 해당 후보에 적용한 후 원본 순서를 유지하여 페이지를 나눔. 현재 페이지의 20개만 필터링하면 안 됨.
- 영양소 드롭다운의 개수는 해당 대상의 필터 적용 전 후보 수(`unfiltered_count`)를 사용함. 목록 개수는 필터 적용 후 개수(`total_count`)를 사용함.
- 드롭다운 UI, 추가 필터 구현, 실제 웹 반영은 웹 담당자가 수행함. 이 패키지는 데이터·연결 함수·한국어 문구·검증 예시를 제공함.
