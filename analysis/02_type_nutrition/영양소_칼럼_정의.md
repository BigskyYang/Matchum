# 영양소 칼럼 정의 (제품분석 파트, 초안 2026-11-02)

팀이 정한 추천 목록(비타민 B·C·A·D·E·K, 칼슘·마그네슘·칼륨·인·아연·철·엽산 / 기능성: 오메가3·유산균·식이섬유·루테인·밀크씨슬)을
데이터로 판정할 수 있는지 기준으로 **분석용 / 고객 안내용 / 제품 매칭용** 3세트로 나눴다. 세 세트는 서로 달라도 된다.

## 1. 분석용 (고객 군집의 '부족 위험' 판정) — 15개
조건: KNHANES 섭취량 열이 있고, 2025 KDRI 기준이 있어야 함

| 영양소 | KNHANES 열 | 기준 | 비고 |
|---|---|---|---|
| 단백질 | N_PROT | EAR | **팀 목록에 없지만 추가 제안**: KDRI EAR 있음, 제품 440개, 고령 군집 다수 |
| 비타민 A·C, 티아민(B1), 리보플라빈(B2), 엽산 | N_VA_RAE, N_VITC, N_B1, N_B2, N_FOLATE | EAR | 엽산 단위 μg DFE로 KDRI와 동일(이용지침서 p240) |
| 칼슘, 마그네슘, 철, 아연, 인 | N_CA, N_MG, N_FE, N_ZN, N_PHOS | EAR | |
| 비타민 D·E, 칼륨, 식이섬유 | N_VITD, N_VITE, N_K, N_TDF | AI | AI 미만은 '부족'이 아니라 참고지표 |

분석에서 뺀 것: **비타민 K, B6, B12, 오메가3, 유산균, 루테인, 밀크씨슬** — 9기 자료(ANALYSIS_BASE·MASTER_CLEAN 모두)에 섭취량 없음.
나트륨: 부족이 아니라 과잉(CDRR) 문제라 추천 판정에서 제외, 주의 문구용.
에너지: 판정 대상 아님, '덜 먹어서 부족한지' 구분하는 보정 변수로만 사용.

## 2. 고객 안내용 (화면 표시)
| 묶음 | 포함 | 안내 방식 |
|---|---|---|
| 비타민 B군 | 티아민, 리보플라빈 | 영양제 추천 가능 |
| 비타민 C / 비타민 A·D·E / 엽산 / 단백질 / 식이섬유 | | 영양제 추천 가능 (A·D·E는 '식사와 함께') |
| 칼슘·마그네슘 / 철·아연 | | 추천 가능, 칼슘↔철·아연은 '따로 복용'(근거 약함 표시) |
| 칼륨, 인 | | **식품으로만 안내** (팀 가이드: 인 영양제 X, 칼륨 식품으로만) |

## 흡수율 반영 (2025 KDRI 원문)
- EAR에 식이 흡수율이 이미 들어 있음: 철 16%(가임기 여 18%), 아연 40%, 칼슘 37~43%, 엽산 DFE (3권 p230·p259·p53, 2권 p372)
- 음주 → 티아민 흡수 저해(2권 p240), 마그네슘 배설 증가(3권 p184) → 음주 군집에서 우선순위 가산
- 흡연 → 비타민 C 증량은 KDRI가 '근거 불충분'(2권 p216) → 적용 안 함
- 같이: 비타민D→칼슘(2권 p91), 비타민C→철(3권 p218) / 따로(근거 약): 칼슘↔철·아연(3권 p50), 철↔아연(3권 p214)
