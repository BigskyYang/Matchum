# 02. 유형별 부족 영양소 (전유환)

12개 생활습관 유형이 같은 성별·나이대보다 어떤 영양소가 더 부족하기 쉬운지 예측하고, 웹 유형 화면에 보여 줄 규칙을 정했습니다.

## 한 일

- **부족의 정의**: 하루 섭취량(24시간 회상)을 본인 성별·연령대의 2025 한국인 영양소 섭취기준(KDRI)과 비교. 평균필요량(EAR)이 있는 11개는 "부족 위험", 충분섭취량(AI)만 있는 4개(비타민 D·E, 칼륨, 식이섬유)는 "참고"
- **예측 모델**: 유형 + 성별 + 연령대 → 영양소 15개 각각의 부족 확률. 영양소마다 로지스틱 회귀·그래디언트 부스팅 10개 후보를 5겹 교차검증과 1-SE 규칙으로 비교 (최종 로지스틱 14개, 부스팅 1개(철))
- **검증**: 2022–23년 학습 → 2024년 평가. 성별·연령대만 쓴 모델보다 AUC +0.014~+0.040, 15개 중 13개 영양소에서 유의 (비타민 D·E는 차이 없음)
- **화면 규칙(2단 표시)**: 성인 절반 이상이 부족한 공통 영양소 8개는 한 줄로 묶고, 그 밖에서 같은 성별·나이 대비 1.2배 이상(부족 확률 0.3 이상) 또는 확률 0.5 이상인 영양소만 유형 영양소로 표시. 학습 자료로 고른 항목이 2024년에도 1.09배(95% CI 1.06~1.12) 더 부족
- **왜 부족한가**: 식사량과 식품군(콩·유제품·달걀 등)을 맞추면 유형 차이의 82%가 줄어듦 → 영양제보다 끼니·식사 구성을 먼저 안내

자세한 근거는 [최종 결과 보고서](../../docs/report/최종결과보고서_iM양식.pdf) 8.5~8.6절에 있습니다.
