# 검증 기록 v1.3.0

2026-11-05. 로컬 테스트 12개 통과. 완전 응답 400가지 조합 검증.

- 같은 생활 4문항 및 입력 코드 유지
- 응답 조합별 이유 생성, 점심/휴일/운동 접점 구분
- 모름을 활동 없음으로 처리하지 않음
- 출퇴근만으로 개인화 카드를 만들지 않음
- 모델 등급/확률은 null, 점수 생성 없음
- 기존 카드 유지, D 중복 방지, 응답 삭제 시 D만 제거
- 기존 제품 함수로 D를 informationCategoryIds에 요청
- 같은 드롭다운에 D 추가, 다른 일반 정보 자동 추가 없음
- 기존 제품 제형 필터 및 페이지 크기 유지

실제 확정 제품 카탈로그 v1.0.1 연결 검사:
칼슘 + D 카드/드롭다운 생성 확인. 일반 대상 D 852개, 칼슘 334개. 각각 첫 페이지 20개 반환. 카탈로그 입력 변경 없음. 응답은 examples/verified_product_connection.json에 기록함. 실제 제품 데이터는 중복 포함하지 않음.

compat의 제품 연결 코드는 기존 v1.0.1과 SHA-256/바이트 동일함.

미검증 범위: 원격 웹의 카드 컴포넌트/필드명, 브라우저 UI, 사용자 건강 효과와 비타민 D 예측 성능. 본 작업은 모델 재학습이나 임상 검증이 아님.
