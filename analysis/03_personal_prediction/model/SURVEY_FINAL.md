# 최종 설문 — v1.4.1 피드백 반영

실제 요청 키와 보기는 config/survey_web.json 참조.

| 항목 | 웹 합의 및 변환 |
|---|---|
| 흡연 유무 | `currently_smoking`: 현재 흡연이면 true → ML_smoker=1, 아니면 false → 0 |
| 흡연량 | 기존 ML_cigarettes_day 특성 유지. 흡연자는 cigarettes_per_day 값 전달, 비흡연자는 0 |
| 유산소 | `aerobic_150min`: 통합 활동 주 150분 이상이면 true → 1, 아니면 0 |
| 규칙적 수면 | regular_sleep_schedule=true; 취침·기상 시각으로 (평일×5+휴일×2)/7 |
| 불규칙 수면 | regular_sleep_schedule=false; average_sleep_hours 직접 입력 |
| 나이 | 웹이 전달한 age를 그대로 사용. 이 패키지에서 나이를 보정하거나 출생연도로 계산하지 않음 |
| 끼니 | 0~3, 3=주 5~7회 |
| 외식 | 0~6, 6=하루 2회 이상 |
| 월간음주 | 빈도 코드 >=2 |
| 과일·채소 | 기존 1~9, 99/모름은 값으로 넣지 않음 |
| mini-FFQ | 육류·생선·달걀·콩류·유제품 5개. 19~64세에서 완비 시 제공 |

나이의 19/64/65 경계도 받은 숫자로 적용함. 웹에서 생년만으로 계산한 값이 만 나이와 다를 수 있다는 피드백은 기록하되, 계산식 수정은 웹 담당 영역으로 둠.

PHQ-9·대사건강·안전 4문항은 포함하지 않음. 일반 스트레스 문항은 기존 모형 입력으로 유지함.
