# 03. 개인 영양 위험 예측 (황재준)

2단계 설문까지 답한 사용자에게, 본인 응답으로 영양소별 섭취 기준 미만(나트륨은 초과) 가능성을 예측합니다. 진단이나 복용량 계산이 아니라 "먼저 살펴볼 영양소"를 고르는 용도입니다.

## 두 모델

| 구분 | 생활습관 모델 | 평소 식사 모델 (mini-FFQ) |
|---|---|---|
| 자료 | 국민건강영양조사 2022–2024 (24시간 회상) | 국민건강영양조사 2012–2016 식품섭취빈도조사 |
| 입력 | 성별·나이 + 흡연·음주·운동·좌식·수면·스트레스·끼니·외식·채소·과일 (18개) | 성별·나이 + 고기·생선·달걀·콩·유제품 빈도 (7개) |
| 대상 | 성인 전체 | 19~64세 |
| 학습 / 평가 | 2022–2023 / 2024년 5,320명 | 2012–2015 / 2016년 3,370명 |
| 모델 | 히스토그램 그래디언트 부스팅 13개 + 로지스틱 회귀 1개(비타민 C) | 로지스틱 회귀 10개 |
| 평균 ROC AUC | 0.664 | 0.877 |

두 모델은 자료와 정답을 만든 방식이 달라 성능을 직접 비교하지 않고, 확률도 평균하지 않습니다. 화면에는 학습 자료 안에서 3등분한 상대 등급(기준 미만 가능성 높은 편·보통·낮은 편)과 예측 출처를 함께 보여 줍니다.

## 폴더

| 위치 | 내용 |
|---|---|
| `model/` | 최종 모델 패키지 v1.4.1 (학습된 모델 24개, 설정, 예측 코드, 검증 보고서). 자세한 내용은 [model/README.md](model/README.md) |
| `vitamin_d_card/` | 비타민 D 생활 4문항 안내 카드 v1.3.0 (학습 모델 없음, 규칙 기반) |
| `survey_schema_v3.json` | 설문 v3 정의. 웹 테스트(`web/src/lib/consistency.test.js`)가 웹 설문과 대조할 때 씀 |

`model/`과 `vitamin_d_card/`는 파일마다 SHA-256 목록(`MANIFEST_SHA256.json`)이 있어 내용을 고치지 않았습니다.

## 웹 연결

웹은 이 모델의 트리와 계수를 JSON으로 옮겨 휴대폰 안에서 계산합니다. 모델이 바뀌면 저장소 루트에서 다시 만듭니다.

```bash
python scripts/export_nutrition_models.py      # model/ → web/src/data/nutritionModels.json (scikit-learn 1.8.0)
python scripts/verify_simulation_nutrition.py  # 웹 계산과 파이썬 결과 대조용 예시 생성
```
