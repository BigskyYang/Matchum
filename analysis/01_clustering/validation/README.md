# 서비스용 생활습관 군집화 검증

**결론과 발표용 정리는 [군집화_결론.md](군집화_결론.md)** — 지연님 12개 유형을 채택하고, 웹용 모델은 `output/nbti_12types.json`.

이 폴더는 두 가지를 한다.
- `01`~`03`: 웹 설문 15개 변수로 만든 비교안(KMeans 7개 유형)
- `04`~`07`: 지연님 12개 유형과 비교·보완·규칙 대조군·경계 분석

## 실행 순서

원시데이터는 `analysis/raw/12~16+22~24년 원시데이터/`의 `hn22~24_all_reduced.csv`를 쓴다 (git 제외).

```bash
python 03_final.py 7 --no-weight   # 최종 모델·검증·이름 근거·웹용 JSON (약 10분) → output/03_최종모델.md
python 05_jiyeon_improved.py 20    # 지연님 12개 유형 보완판: 이름 근거·영양 문구·웹용 JSON (약 15분) → output/05_지연님안_보완.md, nbti_12types.json

python 06_rule_baseline.py          # 군집 vs 규칙 대조군 (얕은 결정나무·사람이 정한 4축) → output/06_규칙대조군.md
python 07_boundary.py 20            # 재학습 때 유형이 바뀌는 사람과 경계 여유, 안내 변화 (약 10분) → output/07_경계분석.md

```

## 과정과 결정

1. **대상자**: 만 19세 이상 17,262명 → 15개 변수 응답 완료 **15,070명** (24시간 회상 있는 사람은 영양 결과 검증에 사용)
2. **변수**: 웹 `encode.js`와 같은 값으로 변환. 지연님 COMPLETECASE CSV의 13개 ML_ 변수와 **100% 일치** 확인
   - `ML_drink_month`는 음주 빈도 ≥ 2와 똑같아서 뺐고, 웹에서 받는 채소·과일 빈도를 더했다
   - **수면**: 2022·2023년은 수면 시간을 직접, 2024년은 취침·기상 시각으로 물어서 2024년만 평균이 0.5시간 길다 → 연도별 표준화, 웹은 2024 기준(같은 측정 방식)
3. **모델 비교** (`output/02_모델비교.md`): KMeans(영역 가중치 있음/없음), GMM, 규칙 기반 4축(MBTI식) × k=3~12
   - 영역 가중치를 주면 안정적이지만 유형 간 영양 결과 차이가 작았고(k=6에서 0.082), 가중치 없이 k=7이 안정성 기준(0.8)을 넘으면서 영양 결과 차이가 가장 컸다(0.174)
   - GMM은 k=4와 6 이상에서 시드 안정성이 낮고(0.59~0.76), 규칙 기반 4축은 16개 중 가장 작은 유형이 0.8%로 너무 작았다
4. **최종**: KMeans, k=7, 표준화만 (영역 가중치 없음)
5. **이름**: 유형 평균의 z로 정하고, 이름에 쓴 특징이 실제로 |z| ≥ 0.3인지 자동 확인 (`03_최종모델.md` '이름 근거')

## 11/3 지연님 12개 유형 보완판 (`05_jiyeon_improved.py`)

유형(사람 배정)은 지연님 원본과 **1:1로 같다** (ARI 1.000). 바꾼 것은 이름·근거·영양 문구·웹 JSON이다.

| 보완 | 결과 |
|---|---|
| 안정성 | 초기화 10 → 50회: 전체 자료에서 같은 해 (이미 최적). KMeans로 바꾸면 총거리 0.15% 차이의 두 4분할 사이를 오가서 결과가 둘로 갈리고 원본과도 달라짐 (ARI 0.42), 합의 선택도 효과 없음 → **원본 알고리즘 유지**, 재학습 안정성 0.70·시간 검증 0.74는 한계로 기록 |
| 이름 | 사람이 읽는 이름 12개 + 대분류 4개, 이름에 쓴 특징 33개 모두 \|z\| ≥ 0.3 통과. 지연님 자동 이름은 대분류 안 상대값이라 전체 기준과 어긋나는 경우가 있음 (예: '규칙식사낮음·외식높음' 유형의 외식 z는 전체 대비 −0.40) |
| 영양 문구 | 총 섭취량까지 보정해도 남는 것만 '유형 특이' (N2 인·철, S1 인), 나머지는 '식사량 영향' → "식사량 점검이 먼저" |
| 개인 신호 | 흡연·음주·채소·과일은 유형을 가르지 않음 (η² 0.04~0.11) → 결과 화면에서 내 응답으로 표시 (`personal_signals`) |
| 웹 JSON | 원래 응답 → 7개 점수가 '상수 + Σ 계수 × 응답' 한 줄 식. JS 재배정 15,062명 100% 일치 |

### 군집 vs 규칙 대조군 (`06_rule_baseline.py`)

"군집이 단순 필터링 아니냐"에 대한 확인.

- **단순 필터가 아니다**: 설문 응답으로 얕은 결정나무를 학습해도 2024년 12개 유형 재현율은 질문 4개(16칸) 65.9%, 질문 6개(62칸) 79.1%. 여러 응답을 함께 봐야 나오는 구분이다
- **대분류는 규칙에 가깝다**: 고스트레스형 ≈ "스트레스 많음 = 예" (일치 93.2%), 비활동형은 유산소 2%·근력 주 0.1일. 대분류는 문항 몇 개로 설명된다
- **영양 설명력은 사람이 정한 규칙과 같다**: MBTI식 4축 규칙(중앙값 기준, 16개)과 영양 차이(+에너지) 0.096 vs 0.096, 2024 AUC 0.630 vs 0.632.
  군집의 장점은 영양 예측이 아니라 유형 수(12 vs 16)·가장 작은 유형(3.0% vs 1.8%)·경계와 조합을 데이터가 정한다는 점
- 정리: 군집은 "규칙보다 영양을 잘 맞힌다"고 주장할 수 없고, "임의 규칙 대신 데이터로 정한 생활습관 구분"으로 설명하는 게 맞다

### 경계 분석 (`07_boundary.py`)

재학습 안정성이 낮은 이유와 안내에 미치는 영향. 표본 40%로 20번 다시 학습하고, 다시 만든 유형을 원래 유형과 겹치는 인원이 최대가 되도록 맞춰(헝가리안 매칭) 비교.

- 재학습 1회에 유형이 바뀌는 사람 평균 19.1%. 경계 여유 10% 미만인 19.8%가 바뀜의 43%를 차지하고, 경계에서 멀수록 덜 바뀐다 (47% → 9%)
- 가장 많이 움직이는 경계는 비활동형 ↔ 좌식·외식형 (끼니 습관은 그대로, 대분류만 바뀜)
- 바뀐 경우에도 59.8%는 영양 안내가 그대로 → 재학습마다 안내가 달라지는 사람은 약 8%

### UMAP 그림 (`08_umap.py`, 시각화 전용)

- 점이 4개 섬으로 갈리는데, 섬은 스트레스 많음(예/아니오) × 유산소 실천(예/아니오) 조합과 그대로 겹친다 → 생활습관 집단이 아니라 예/아니오 문항이 만든 모양
- 같은 섬 안에서 세부 유형끼리는 틈 없이 맞닿아 있고, 경계 여유 10% 미만인 사람은 섬 안 곳곳에 퍼져 있다
- UMAP은 군집 입력으로 쓰지 않는다 (없는 덩어리를 만들고 설정에 따라 바뀌며, 웹에서 새 사용자를 배치하기 어렵다)

## 한계

- **수면·스트레스·좌식·유산소는 유형을 거의 가르지 않는다** (η² 0.01~0.06). 이 네 가지는 유형이 아니라 개인 결과(내 응답 그대로)로 보여주는 게 맞다.
- 점심·저녁을 거르는 사람은 적지만(각 3~7%) 표준화 후 차이가 커서 따로 유형이 됐다. 영양 결과 차이가 가장 커서 서비스에는 의미가 있지만, 끼니를 적게 먹은 날의 24시간 회상이라 섭취량이 낮게 나오는 효과가 섞여 있다.
- 실루엣이 낮아 '자연스러운 집단을 발견했다'고 말할 수는 없다. 연속적인 생활습관을 이해하기 쉽게 나눈 구분이다.
- 영양 결과는 하루 24시간 회상 기준이라 평소 섭취와 다를 수 있다.
