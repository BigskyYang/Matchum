# 01. 생활습관 군집화 (최지연 · 검증 양대천)

| 위치 | 내용 |
|---|---|
| `kmedoids_final.py` | 2단계 K-medoids (7개 지표 → 표준화 → PCA 5차원 → 대분류 K=4 → 대분류마다 세부 K=3) |
| `kmedoids_model.json` | 웹과 같은 계산으로 재배정할 수 있는 군집 모델 (표준화·PCA·대표점) |
| `cluster_report.md` | 방법, k 선택, 세부 변수 조합 선택, 검증 |
| `세부군집_탐색/` | 대분류별 세부 변수 조합 56개 탐색과 세부 k 비교 |
| `null_test/`, `생활습관 군집 귀무검정 결론 보고서.pdf` | 무작위 자료와 비교한 귀무 검정 |
| `추가검증/`, `dimred/` | 유형 섞기·시간 검증, 차원 축소 방식 비교 |
| `validation/` | 웹 설문 기준 비교안, 규칙 대조군, 경계 분석, 웹용 12유형 모델(`output/nbti_12types.json`). 결론은 [validation/군집화_결론.md](validation/군집화_결론.md) |

원자료(`KNHANES_2022_2024_ML_CLUSTER_COMPLETECASE.csv`)는 저장소에 없습니다. 이 폴더에 두고 실행합니다.

## 📊 군집 분석 결과 (12개 유형)

KNHANES 2022–2024 성인 **15,062명**을 생활습관으로 분류했습니다.
운동·식사·좌식·스트레스 7개 지표로 **4개 대분류**를 만들고, 대분류마다 다른 기준으로 **3개씩 세분화**하여 최종 **12개 유형**입니다.

> 흡연·음주는 군집 기준에서 제외했습니다. 이 변수들이 너무 강해서 다른 생활습관을 가려버리기 때문입니다(개선 전에는 흡연 하나가 군집 분산의 96%를 설명). 유형별 참고 수치로는 함께 제공합니다.
> 수치는 모두 `KMedoids_Lifestyle_12Types.xlsx`의 실제 평균값입니다. 방법과 검증은 `cluster_report.md`를 참고하세요.

| S2 | `G2_고스트레스형_0` | 산책하는 예민보스 | 스트레스는 많지만 유산소 활동을 꾸준히 하는 편이에요. | 스트레스 유산소형 |
| S3 | `G2_고스트레스형_2` | 쇠질하는 예민보스 | 스트레스는 많지만 근력운동을 자주 하는 편이에요. | 스트레스 근력운동형 |

> **ID 번호와 모델 코드 끝 번호는 일치하지 않습니다.** 모델 코드 끝의 `_0`·`_1`·`_2`는 군집화 때 붙은 순서일 뿐 의미가 없고, ID(N1~O3)는 각 유형의 실제 평균값을 보고 정한 서비스용 번호입니다. 그래서 A1이 `G1_운동형_1`, A2가 `G1_운동형_0`처럼 번호가 엇갈립니다. 웹(`types.js`)·보고서·`추가검증.py`가 모두 이 표의 연결을 따르므로, 코드와 ID를 오갈 때는 반드시 이 표를 기준으로 하세요.

## 🦥 N. 나무늘보 — G0 비활동형 (4,489명)
운동을 거의 하지 않지만 스트레스가 가장 낮고 수면이 긴 안정적 그룹입니다. 좌식 시간도 476~537분으로 짧은 편입니다. **외식과 식사 규칙성**으로 세 유형으로 나뉩니다.

* **N1 집밥좋아 나무늘보 (`G0_비활동형_0`, 1,802명)** — 외식 0.61로 전체 최저. 삼시세끼를 거의 다 챙겨 먹습니다(아침 2.95, 점심 2.99, 저녁 3.00).
* **N2 배고픈 나무늘보 (`G0_비활동형_1`, 1,258명)** — 아침 1.28, 점심 2.46으로 끼니가 불규칙합니다. 수면은 7.64시간으로 긴 편.
* **N3 배부른 나무늘보 (`G0_비활동형_2`, 1,429명)** — 외식 2.71로 잦지만 세 끼는 규칙적으로 먹습니다.

## 🔥 A. 갓생러 — G1 운동형 (4,171명)
좌식 시간이 403~467분으로 가장 짧고 스트레스도 낮습니다. **근력 강도와 식사 규칙성**으로 나뉩니다.

* **A1 뚜벅이 갓생러 (`G1_운동형_1`, 1,542명)** — 유산소 99%, 근력 0.27일. 좌식 403분으로 전체 최단이고 세 끼를 챙겨 먹습니다.
* **A2 파워 갓생러 (`G1_운동형_0`, 1,124명)** — 근력 주 2.67일, 유산소 88%. 다만 아침 1.23으로 끼니가 불규칙합니다.
* **A3 밸런스 갓생러 (`G1_운동형_2`, 1,505명)** — 근력 주 4.36일(전체 최고). 식사도 규칙적입니다(아침 2.93).

## 😤 S. 예민보스 — G2 고스트레스형 (3,444명)
스트레스 인지율 82~97%로 가장 높고, 수면이 6.99~7.10시간으로 가장 짧습니다. 아침 결식이 잦고(1.54~1.67) 외식이 많습니다. **운동 여부**로 나뉩니다.

* **S1 쉬고 싶은 예민보스 (`G2_고스트레스형_1`, 1,561명)** — 운동 없음, 좌식 602분, 수면 6.99시간. 가장 취약한 조합입니다.
* **S2 산책하는 예민보스 (`G2_고스트레스형_0`, 1,429명)** — 유산소 100%, 근력 0.06일.
* **S3 쇠질하는 예민보스 (`G2_고스트레스형_2`, 454명)** — 유산소 77% + 근력 3.18일. 스트레스 97%로 가장 높고 외식도 3.54로 최다.

## 💼 O. 워커홀릭 — G3 좌식·외식형 (2,958명)
하루 앉아 있는 시간이 675~708분(약 11~12시간)으로 가장 길고, 외식 3.98~4.26으로 가장 잦습니다. 스트레스는 낮습니다. **근력운동과 식사 규칙성**으로 나뉩니다.

* **O1 아침패스 워커홀릭 (`G3_좌식외식형_0`, 1,228명)** — 아침 0.79로 전체 최저.
* **O2 삼시세끼 워커홀릭 (`G3_좌식외식형_1`, 1,137명)** — 좌식·외식이 많아도 세 끼는 챙겨 먹습니다(아침 2.79).
* **O3 운동하는 워커홀릭 (`G3_좌식외식형_2`, 593명)** — 근력 주 3.09일. 다만 좌식 708분으로 전체 최장입니다.
